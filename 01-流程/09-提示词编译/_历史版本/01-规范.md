# 脚本转视频提示词规范

## 目的与边界

本规范用于把已经定稿的脚本转成视频模型或摄制团队可执行的镜头指令。上游是脚本，下游是生成、实拍或后期；改编阶段不重写剧情、不添加未经确认的卖点，也不把剪辑时码伪装成模型参数。

一个提示词对应一个可独立理解的镜头或生成片段。优先保留脚本的剧情、台词、产品事实、品牌信息和拍摄分工；模型版本或入口未明确时，输出平台中性稿并把能力项标为待确认。

## 转换规则

| 编号 | 规则 |
|---|---|
| R01 | 忠实脚本。保留原剧情、台词、时序、品牌事实和硬约束；发现冲突先标注，不擅自改成另一版脚本。 |
| R02 | 先判定镜头路线。按原稿区分 AI 生成、实拍、实拍加后期、克隆/数字人和纯后期；不要把原计划的真实食物、门店、群众镜头无理由改成 AI 生成。 |
| R03 | 一镜一件主要动作。复杂动作拆成可剪辑的镜头；单镜只安排一个主要动作或信息点。 |
| R04 | 先写主体。明确镜头里的主要人物、物件或食物；有身份锁定要求时，重复足以辨认的外形、服装和道具锚点。 |
| R05 | 动作写成可见过程。交代起始状态、动作部位、方向/速度、关键变化和结束状态；不用抽象情绪代替动作。 |
| R06 | 镜头指令可拍。写景别、机位/角度、主运镜、焦点；没有运动就写固定机位。避免互相冲突的双重运镜。 |
| R07 | 分开剪辑时码与模型时长。保留脚本的片段起止、剪辑长度和片内动作节拍；只有当前模型入口确有该时长选项，才将其写成生成参数。 |
| R08 | 参考素材要有标签和职责。说明图片/视频/音频各自决定什么、在何时使用；人物、服装、场景、动作和风格不要混为一个“参考”。素材未提供时用待补占位，不写成已上传。 |
| R09 | 连续性逐镜继承。角色、服装、头盔/面罩、道具、场景、色温、方向、数量和动作接点在每条独立提示词里复述必要信息。 |
| R10 | 声音分层。对白保留原句并标说话人和发生点；环境声、动作音效与配乐分开写，注明谁在对白时占前景。 |
| R11 | 屏幕文字与标识单列。字幕、店名、Logo、AI 标识和价格信息逐字锁定；需要准确呈现的文字优先后期叠加，除非脚本或入口明确要求模型生成。 |
| R12 | 把抽象词改成画面证据。核心提示词不单独用“高级、电影感、自然、有质感”等词充当指令；如保留风格标签，必须紧跟可观察的构图、光线、动作、材质或剪辑说明。 |
| R13 | 约束标明放置位置。区分主提示词中的正向锁定、模型独立负面栏、实拍现场提醒和后期质检；平台没有独立负面栏时，不把负面词列表硬塞入主提示词。 |
| R14 | 不虚构模型能力。未核对的帧率、比例、时长、上传数量、首帧锁定、音频生成、参考标签语法和负面栏都写“待当前入口确认”。 |
| R15 | 交付前核对。检查时长合计、动作顺序、台词可说完、素材职责、人物连续性、屏幕文字、声音层级和生成/实拍分工。 |

## 单镜固定字段清单

每条镜头卡都填全下表。脚本未提供的字段写“未提供 / 待确认 / 无对白”，不要留空让模型猜。

| 必写字段 | 写什么 | 为什么 |
|---|---|---|
| 镜头编号与片段时段 | 镜号、成片中的起止时码、剪辑目标长度；另列模型生成长度待确认 | 对应脚本原位置，检查总时长和剪辑顺序；时码本身不保证模型精确执行。 |
| 生成/拍摄路线 | 文生、图生、参考生、编辑/续写，或实拍/后期 | 决定主提示词怎样写、参考素材是否需要上传，也防止把实拍镜头误交给模型。 |
| 画面主体 | 主体身份、外形、服装、产品/道具关键特征及位置 | 没有主体锚点时，角色和产品容易被替换、增减或变形。 |
| 场景与首帧 | 地点、时间、空间布局、前中后景、主体位置/朝向/起始姿势、焦点和留白 | 给模型明确的画面起点；也便于参考图或美术稿与动作接续。 |
| 动作节拍 | 起始状态 → 动作过程/先后 → 结束状态；需要时标动作发生区间 | 视频生成必须知道画面如何变化，不只是画面里有什么。 |
| 镜头语言 | 景别、机位/角度、一个主运镜、焦点对象 | 决定画面尺度、视点和运动关系。 |
| 光线与可见细节 | 光源方向/色温、主体材质、环境运动和关键视觉细节 | 把“电影感/食欲感”等抽象词转换成具体生成线索。 |
| 参考图/视频/音频 | 标签、实际/待补状态、参考职责、作用时间、必须保留和不继承的内容 | 防止模型把参考图的背景、服装、构图等不相关信息一并照搬。 |
| 声音 | 对白原句/说话人/语气，环境声、动作音效、配乐分别列出；不需要则明确写无 | 防止对白归属错、音效盖住台词或擅自生成声音。 |
| 字幕与画面文字 | 内容、出现时点、位置；准确商标/店名是否改为后期叠字 | 模型写字可能不准确；商业信息不能由模型随意补全。 |
| 连续性与限制 | 必须保持项、不得新增项，以及限制放入提示词/负面栏/拍摄表/后期表的位置 | 锁定身份、产品、空间和物体数量，同时避免不兼容的负面语句。 |
| 出点与衔接 | 最后一帧状态、切点、动作/视线/声音桥接，以及接下镜头的锚点 | 让独立镜头仍能剪成连贯成片。 |

## 脚本三列到提示词字段的接口

| 脚本列 | 提示词落点 | 转换方式 |
|---|---|---|
| 时段 | 镜头编号、成片入/出点、剪辑长度、片内动作节拍 | 原样保留脚本时码；将动作拆成先后节点。模型时长单独列为待确认设置。 |
| 画面 | 主体、场景/首帧、动作、镜头、光线/细节、参考素材、连续性、画面限制 | 先抽取主体与主动作，再补可拍的构图/机位和参考素材职责。字幕、Logo 等视觉文字另列。 |
| 声音 | 对白、环境声、音效、配乐、字幕/后期音画同步 | 原句不改；写明说话人和发生时点。环境声和拟音进声音场景，配乐独立列，准确字幕在后期核对。 |

### 某一列缺失时

- **缺时段：**若总片长和镜头顺序已知，给出“编辑节奏估算”并列出分配依据；若时长会改变动作/台词结构，先标待定。不得把估算说成平台生成时长。
- **缺画面：**只从相邻脚本信息和已提供素材中提取；仍无法确定主体、地点或动作时，保留待补字段，不编造核心剧情。
- **缺声音：**写“脚本未指定对白/音效/音乐”。不新增台词或拟音；如需保持真实现场声，标为拍摄/后期建议，不写成模型已生成。
- **部分缺失：**已知项照常转换，未知项逐镜标注；不因一列缺失而丢掉另两列。

## 禁用词与替代写法

下列词不是禁止出现在创意简报里，而是禁止单独充当可执行提示词。使用时必须改成能被镜头看到/听到的描述。

| 不可单独使用 | 可执行替代写法 |
|---|---|
| 高级、高级感 | 写材质、色彩、布光和构图，例如“深色木桌、暖黄顶灯、背景客人虚化，画面左侧留白”。 |
| 电影感、大片感 | 写景别、机位、运镜、光线和节奏，例如“中近景固定机位，冷色顶光压住街景，切入室内时白平衡转暖”。 |
| 自然、真实 | 写具体行为和观察点，例如“眉毛先皱起、嘴唇动一下没出声，停半拍后只回一个字”；或写素材来源“实拍门店、真实烤盘”。 |
| 有质感、很有质感 | 写材料和光学表现，例如“银色磨砂金属面罩有细接缝和轻微磨损，左上侧光在右侧形成柔和阴影”。 |
| 震撼、很炸、氛围感 | 写事件、尺度和可见变化，例如“云层从中央翻暗，一道大阴影斜掠过楼顶；不出现飞船本体”。 |
| 食欲感、诱人 | 写食物的状态和运动，例如“肉片边缘卷起、脂肪起细泡、油汇成薄亮层，白烟向上散开”。 |
| 清晰、细腻 | 写焦点和细节，例如“焦点锁定在面罩接缝和金属磨痕，背景虚化；眼缝亮度稳定”。 |
| 轻微、偶尔、微微一笑 | 写发生位置、次数或变化过程，例如“眉头由放松转为皱起；嘴角保持不动，眨眼一次”。 |
| 反应、看向、做动作 | 写动作部位和方向，例如“右手把饭盒向下倾斜，餐盒里的食物落到脚边；他抬头看向画面上方，不低头追看”。 |
| 4K、高清、某帧率等规格词 | 只填入已核实的生成界面设置；未核实则列为待确认项，不当作画质提示词。 |

## H3 字段映射（按随附 Skill 中可见信息）

- T2VA / I2VA / FL2VA / L2VA 使用字段顺序：integrated_multimodal_description → overall_soundscape → non_diegetic_music。
- Ref2VA 使用字段顺序：subject_definitions → summary → retention_analysis → detailed_description → overall_soundscape → non_diegetic_music。
- H3 Skill 要求英文重写段落，台词、歌词和可见文字保留原语言；参考标签全篇一致，描述参考内容具体出现的时间点。
- 上述名称与顺序来自随附的 SKILL(1).md。其引用的 references/base-en.txt 与 references/ref-en.txt 没有随附件提供，因此本文件不声称掌握那两份文件的完整语法。

## 情侣对话、克隆角色与多人镜头补充

第二份某烤肉店脚本提供了情侣对话样本。以下是从脚本的分工与镜头设计推导出的制作规则，不代表生成效果已验证：

- **先确定路线再写提示词：** AI 单人镜、克隆角色镜、实拍微反应、AI 与实拍拼接、纯实拍、后期合成分别建卡。不得把“AI＋实拍”误读成一次生成任务。
- **双人同框先拆解风险：** 如果两个人的微表情、口型或身份一致性都重要，优先设计正反打、手部特写或剪辑拼接；确需同框时，先写清两人的画面位置、动作和视线关系，并将其列为需验证镜头。
- **克隆/数字人引用不能靠含糊称呼：** 明确是平台内已建角色、人物图片/视频参考，还是尚未提供的素材；为每种引用指定身份、服装、场景或动作职责。未确认入口能力时写“路线待确认”。
- **微表情拆成能拍到的变化：** 例如“嘴角笑意收住 → 夹子停在半空 → 眼神移向烤肉”，不要只写“心虚/生气/真香”。动作顺序不可互换时写出先后。
- **首帧先锁空间关系：** 写主体在画面中的位置、视线方向、手里物件、桌面/背景锚点与焦点；镜头运动从这个状态开始。每镜需要独立执行时，重复必要的角色和场景锚点。
- **声音按制作路径分配：** 原稿若把对白、字幕、音效、BGM 分列，分别进入声音提示、后期字幕清单或剪辑节奏表；不得把字幕误当台词，也不得默认目标模型能同时完成所有音轨。

这些补充遵循 R02、R03、R05、R08、R09、R10、R13、R14；脚本3中关于正反打和实拍微反应的具体建议只作为该项目方案记录。

## 古装与现代门店反差镜头补充

第三份脚本使用古装角色进入现代烤肉店的反差喜剧结构。转换时补充以下镜头设计要求：

- **钩子按节拍拆开：** 食物特写、黑场停顿、角色/场景揭示、字幕分别标时点；字幕与黑场由剪辑/后期精确控制，不能假设生成模型会准确写字或卡点。
- **跨时代反差写成画面关系：** 明确古装人物、现代桌椅/烤炉、店内环境分别在前景/中景/背景的位置，避免只写“古今碰撞”。
- **避坑做法只当方案，不当能力结论：** 烟雾遮挡、只拍动作前后状态、避开手部等可以列为备选镜头方案；“唯一稳定”“必然规避”等效果结论必须放入待验证栏。
- **系列连续性逐项锁定：** 店景、老板衣服、贵妃造型、桌面与烤炉分别指定参考来源；参考图缺失时标待补，不承诺跨片一致。
- **音效素材单列：** 滋啦、吞咽、炉火、环境声、音乐的来源与剪辑点分别标记。脚本若要求使用外部音效，应记为后期素材任务，不默认交给模型生成。

该补充遵循 R02、R06–R11、R14；脚本中的具体拍法和营销判断仍需以来源/推导/待实测分类。

## 反向推导的总控提示词

下面这段可直接交给 AI，用于把已经定稿的短视频脚本转换成逐镜执行稿。它来自三份某烤肉店脚本、旧烤肉特写示例和用户提供的 H3 Skill 结构分析；它是转换指令模板，不代表任何平台已实测。

```text
你是“定稿脚本 → 视频生成/拍摄执行提示词”的导演助理。上游输入是已定稿脚本，下游输出是可交给目标视频模型、实拍团队和剪辑人员执行的逐镜提示词及制作说明。

【输入信息】
- 脚本全文/附件：{粘贴或读取}
- 目标平台/模型及具体入口：{未指定则写“平台中性”}
- 成片比例与目标时长：{填写；未知则标待确认}
- 画面风格：{填写；未指定则依据脚本归纳并标明}
- 可用角色、场景、道具、首帧/参考图/视频/音频：{列清单；没有则写“未提供”}
- 必须保留的台词、品牌信息、限制和版本：{填写}

【工作原则】
1. 不重写定稿剧情，不擅自增删笑点、台词、产品事实、品牌承诺或镜头顺序。发现脚本自身矛盾、动作不可见、时长疑似不够或制作路线不明，先列为问题并保留原稿，不替用户做内容定稿。
2. 先读取并记录采用的脚本版本、总时长、镜头数、画幅、镜头时码和制作路线。不要仅凭文件名判断版本；同编号但标题/剧情不同的文件按独立稿处理，除非用户明确说是替代稿。
3. 逐镜判断制作路线：文生/图生/参考图生/角色或数字人/实拍/实拍加后期/纯后期。遵守原稿分工。混合路线拆成各自独立素材与剪辑接法，不把“AI＋实拍”误写成一次模型生成任务。
4. 每镜只突出一个主要动作或信息点。把动作写成“首帧状态 → 动作过程 → 结束状态”，明确先后、方向、主体与道具位置。情绪词转换为可观察表演，不只写“自然、惊讶、心虚、真香”。
5. 每镜必须有首帧构图、画面主体、动作、景别/机位/运镜/焦点、成片时码与剪辑长度、参考素材职责、声音/对白、文字/字幕处理、连续性锚点、负面约束和镜头衔接。脚本缺项写“未提供/待确认/无”，不可留空让模型猜。
6. 首帧描述主体位置、朝向/视线、起始姿势、关键道具、前中后景、背景锚点和焦点。首帧是画面设计描述，不等于平台支持首帧锁定；平台功能未确认时不要这样声称。
7. 对角色、服装、发型、道具、店景、桌面、光线、方向与数量建立连续性表。逐镜只重复当前镜头执行所需的锚点。每张参考图/视频/音频标注标签、状态、负责属性、使用时点，以及不应继承的内容。素材未提供时只写待补占位。
8. 把脚本时段当成成片剪辑时码，不自动当作模型生成时长。台词、停顿和动作是否能装入剪辑时长要核算；有疑问就标出“需核语速/待剪辑确认”，不擅自删词。
9. 声音拆成角色对白/画外音、现场环境声、动作音效、BGM。保留原句，标说话人、发生点和前后景关系。字幕不等于对白；准确字幕、店名、Logo、价格、定位、AI标识按脚本单列，优先标为后期叠加。
10. 负面约束写具体可检查事项，如“不换服装、不新增人物、夹子不穿手、肉片不变形、不要生成文字”。把约束标明应进入正向提示词、平台负面栏、实拍提醒或后期检查；目标平台是否有独立负面栏未知时，不虚构字段。
11. 禁止把“高级、电影感、自然、有质感、震撼、食欲感”等抽象词单独当成执行指令。若需保留为风格标签，紧跟构图、光线、材质、动作、声音等可见证据。
12. 钩子、黑场、闪字、反转、静音点和卡点拆成明确节拍；需要精确文字、黑场时长、Logo或音效落点的，标给剪辑/后期，不承诺模型会精确执行。
```

### 这段总控提示词如何从样本反推

- 三份脚本共同出现时码、画面/动作、对白或声音、字幕/文字和制作分工，因此列为逐镜接口的必填项。
- 外星人脚本强调跨镜身份与参考图职责；情侣脚本强调微表情顺序、克隆角色和双人镜头拆分；贵妃脚本强调开场钩子、黑场/字幕/音效切点和跨片造型复用。因此总控词将这些写成专项检查，而非只输出一段风格描述。
- 旧烤肉特写提示词提供主体、动作、镜头、食物细节、光线、声音和约束的单镜骨架；H3 Skill 提供特定字段组织参考。总控词要求先平台中性，再按已核实目标入口适配，避免将一个平台的字段冒充通用格式。
- “某种手法唯一稳定”“校验100分”等来源说法不作为有效性证据；提示词要求把来源、推导和实测分开。
