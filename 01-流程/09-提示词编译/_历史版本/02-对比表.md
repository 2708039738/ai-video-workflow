# 三类材料横向对比

## 对比对象与范围

1. **子龙 Skill：** 用户提供的 MiniMax H3 Prompt Writing（SKILL(1).md）。附件列出 H3 生成模式、字段名和工作流程，并引用两份未随附件提供的参考文件。
2. **群里脚本：** 用户提供的三份某烤肉店短片脚本：《脚本5 外星人入侵地球结果被一顿烤肉收买》《脚本3 女朋友和烤肉同时掉水里先救谁》《脚本3 贵妃第一次吃烤肉·钩子强化版》。分别为45秒21镜、45秒13镜、约45秒10镜。后两份文件都标“脚本3”，但剧情完全不同，本表按两条独立创意处理，不推断版本替代关系。
3. **旧项目提示词：** 此前「精准脚本写法」对话中出现的烤肉特写 4 秒提示词示例。它是单镜头文本，不是完整 45 秒脚本，也没有独立素材文件。

下表比较文档中实际出现的内容；“指令密度”是结构观察，不是生成效果测量。

## 共同骨架

- 先明确镜头里是谁/是什么，再写发生的动作和场景。
- 镜头不是静态美术说明：需要动作顺序、时间或可观察的过程。
- 摄影机/镜头语言应具体到景别、角度、焦点或运动。
- 声音不应被挤进模糊的“氛围”描述；对白、环境声、音效和配乐要分清。
- 跨镜头需要固定人物、服装、场景、道具和关键参考素材。
- 生成约束和限制都要明确，但应按目标模型的格式放置。

这些是对三类材料的结构归纳，不代表已经证明它们能提升生成命中率。

### 三份脚本的共同骨架与独有字段

- **共同骨架：** 镜号/时段、画面主体与动作、台词/声音、字幕或画面文字、制作路线/参考素材职责；需要把剪辑时码与模型生成长度分开。
- **脚本5独有重点：** 多镜头的 AI/实拍/后期路线和外星角色参考连续性。
- **情侣脚本独有重点：** 克隆形象、微表情动作顺序、双人互动拆拍、正反打与声音停顿。
- **贵妃脚本独有重点：** 开头钩子节拍、黑场/字幕/音效切点、古装与现代店景的同框反差、系列造型复用和食物动作避坑。
- 三份脚本没有提供同一模型的生成结果；共同字段是文本结构的交集，不是效果排名。

## 关键差异与取舍

### 1. H3 是模型接口，脚本是制作接口

H3 Skill 侧重模式选择和固定字段；某烤肉店文档侧重整条片子的制作路线，明确了哪些镜头要生成、哪些必须实拍、哪些靠后期。转换时先尊重制作路线，再把需要生成的镜头装入目标模型接口。

### 2. 单镜提示词不能替代全片镜头表

旧提示词适合说明一个 4 秒食物近景，却不能承载 45 秒的剧情转折、AI/实拍分工和 BGM 结构。全片表负责顺序与剪辑，单镜 prompt 负责模型执行。

### 3. 图片标签的价值在于“指定继承项”

H3 Skill 与某烤肉店脚本都要求可追踪的参考标签；旧提示词主要靠“前一镜头中的人物”文字承接。定稿规范采用标签加职责，并要求每条提示词复述关键锚点，避免模型依赖看不到的对话上下文。

### 4. 形容词必须转换成画面细节

旧提示词把“暖色电影感布光”与食物油光、微焦和热气并列。某烤肉店脚本进一步用云层变暗和移动阴影替代“直接生成巨型飞船”。本规范保留可观察的结果，把抽象风格词降为标签。

### 5. 密度不是越高越好

某烤肉店脚本有丰富的制作约束，但单镜提示词仍应突出一个主动作和最重要的限制。参考职责、灯光、道具和声音按当前镜头是否需要分配，不把整份企划重复粘贴进每条生成指令。

## 对规范的直接影响

- 用“全片制作表 + 单镜提示词”两层结构，不把 45 秒故事压成一段长提示词。
- 保留时段、画面、声音三列接口，同时明确实拍/生成/后期路线。
- 所有镜头都填主体、动作、运镜、时长和参考素材职责；没有的信息明确写无/待确认。
- H3 定稿按 H3 字段顺序输出；其他平台先做平台中性稿，不借用 H3 的字段名或未知参数。
- 03 示例逐镜标出本规范规则编号，让读者能从脚本列追到提示词字段。
