## 推的：材料综合后的规范

| 推导项 | 依据 | 本版结论 |
|---|---|---|
| 单镜固定清单必须包含主体、动作、运镜、剪辑时长、参考素材职责。 | H3 字段、脚本列和旧提示词结构的交集。 | 01 将这些列为必填；缺少时写“无/待确认”。 |
| 脚本“时段/画面/声音”应分别落到时码与动作节拍、主体与镜头、对白/环境音/音效/配乐。 | 某烤肉店脚本的三列内容与 H3 多模态结构。 | 01 提供逐列映射及缺列处理。 |
| “高级、电影感、自然、有质感”等不得单独作为执行指令。 | H3 Skill 要求具体视听描述；两份某烤肉店脚本和旧提示词都提供了抽象风格标签与/或可见细节。 | 01 列出具象替代。这是写作规范，不是生成效果结论。 |
| 全片制作表与单镜生成提示词分开。 | 两份群聊文档同时包含多镜表、路线分工和制作说明；旧提示词只描述一个镜头。 | 03逐镜展开路线与执行指令。 |
| 成片剪辑时长与模型生成长度分开。 | 脚本短镜与 H3 Skill 提到的时长范围不同。 | 01、03 不把时码写成模型参数。 |
| 参考图职责拆开，角色参考不自动带入其背景。 | H3 的标签一致性要求和群聊脚本的分图参考。 | 03 为图片定义用途；因图未附，提示词暂不能按真实图像执行。 |
| Ref2VA 的 retention_analysis 写参考保留项，detailed_description 写动作/镜头变化。 | 附件只给字段名和顺序，未给字段正文模板。 | 这是按字段名称义推写，未确认符合缺失的 ref-en.txt 全部要求。 |
| 对情侣互动镜先拆成女主侧、男主实拍反应和手部素材，再用剪辑拼接；微表情写为动作顺序。 | 脚本3给出正反打/实拍微反应做法，且“先收笑意、再压嘴角”等细化表演动作。 | 03按该项目制作方案拆镜；这是脚本适配选择，不是跨模型实测结论。 |
| 脚本3的参考图按人物身份、桌面/烤盘、环境分工，不让角色参考承担整个场景。 | 脚本3角色提示词/参考字段写法；图片本身未提供。 | 01补充职责拆分；03保留待补标签，实际继承效果待测。 |
| 古装角色与现代烤肉店的反差应拆为角色造型、现代环境、桌面/烤炉等可见画面关系；开头的黑场、闪字、音效由剪辑层控制。 | 贵妃稿把“古今碰撞”与钩子节拍写在创意/分镜中；模型入口能力未知。 | 01、03将视觉关系具体化，将准确文字与时间切点交给后期；这是转换设计，不是效果结论。 |
| 贵妃稿没有提供镜头机位/参考图上传标签的完整字段，因此需要在提示词转换中补首帧与构图。 | 贵妃分镜表的字段只有镜、时长、画面、台词、字幕、音效；参考图未附。 | 03补的首帧/机位明确标为转换设计，不声称原稿已有。 |
| 贵妃稿镜3同时要求“老板擦桌子”和“只拍肩和桌面、不拍手”，可见擦拭动作与避开手部存在画面执行张力。 | 贵妃钩子版 DOCX镜3画面描述。 | 03先将擦拭动作放在画框外并标出取舍；若必须看清擦桌动作，需制作方确认是否允许手入画。 |
