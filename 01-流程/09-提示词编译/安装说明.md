# AI 视觉导演 · 使用说明

一份给 AI 视频/图片提示词工作的技能包。可直接放进 Claude Code、WorkBuddy 或其他能读本地文件的 agent 运行。

## 放哪儿

- **Claude Code / Claude Desktop(带 Skills)**:`~/.claude/skills/ai-visual-director/`,放整个目录,入口是 `SKILL.md`
- **WorkBuddy**:`~/.workbuddy/skills/ai-visual-director/`
- **其他 agent**:把整个目录给它,让它先读 `SKILL.md`,再按需读 `references/`

目录里只有两类东西:`SKILL.md`(主文件,agent 必读)和 `references/`(按需加载)。技能本身没有脚本依赖、也不调用任何付费接口;**只有做「生成后验收」时需要 ffmpeg**,其中机位漂移那一步可选地用到 Python + numpy + PIL,没有就跳过并标 `待核实`。

## 它会做什么

| 你给什么 | 它进入 | 产出 |
|---|---|---|
| 只有想法/产品/主题 | 模式 A | 先澄清意图 → 脚本 |
| 定稿脚本或单图需求 | 模式 B | 逐镜头提示词卡 / 图片卡 |
| 已有提示词 + 生成结果 + 落差 | 模式 C | 差异清单 → 诊断 → 改写 |
| 只有参考图/参考视频 | 模式 D | 可观察要素 → 提示词 |

## 跑之前要知道的三条

1. **它不替你花钱**。不调生成接口、不跑实验,除非你明确要求。
2. **它不改你的事实**。台词、屏幕文字、品牌文案逐字保留;价格、功效类标 `未独立核实`;绝对化用语标 `需确认:广告用语`,既不删也不下合规结论。
3. **没生成过就不说成功**。任何"有效/已测试"必须有实际生成结果支撑。

## 一个最短的调用例子

> 帮我把这段 30 秒竖屏招生脚本转成逐镜提示词卡,标出哪些镜头 AI 生成风险高。

它会走模式 B:锁定脚本版本 → 建参考台账 → 七类冲突排查 → 逐镜出卡 → 平台适配 → 质检。

## 已知边界

- 精确文字(招牌、字幕、价签)默认交后期,不指望模型写对。
- 口型与语音的逐帧同步是弱项,只能靠音频驱动改善,不能承诺。
- 口播"自然"必须真人念过才能说,否则写 `待补:真人念读`。
