# 去 AI 感手法

> **性质：加分项，不是必过项。** 只有第一节的"同一时空光影自洽"是硬性要求，其余按片型选配。
> 依据来源：抖音 AIGC 商业短片创作者稣文的 21 条拆解，标注了出处编号（V12 / V14 / V02）。
> 这些是**方法论，未在本项目实测**，标 `待核实`。

## 一、硬性：同一时空内的光影必须自洽

**不是"所有镜头光影统一"，是"同一场景、同一时间段的连续镜头必须自洽"。**

### 必须一致

| 项 | 说明 |
|---|---|
| 光源方向 | 上一镜主光从左前方来，这一镜不能突然从右后方来 |
| 人物主光关系 | 左脸亮 / 右脸亮，连续镜头里不能颠倒 |
| 色温 | 同一空间不能一镜偏暖一镜偏冷 |
| 阴影方向 | 地面投影、墙面影子要朝同一侧 |

### 允许不同，而且应该不同

| 情况 | 处理 |
|---|---|
| 换场景（店内 → 店外） | 光本来就会变，但要在镜头里交代过渡 |
| 时间变化（白天 → 夜晚） | 同上，允许大跳，但要让观众知道时间变了 |
| 剧情内光变（开灯、拉窗帘、走近窗边） | 必须有触发动作，不能凭空空变 |
| 刻意的戏剧反差 | 允许，但要能说出为什么 |

### 判断方法

问一句：**这一镜和上一镜，是不是"同一个时刻的同一次发生"？**

- 是 → 光影必须自洽
- 不是 → 允许变化，但要有变化理由

### 为什么是硬性

观众说不出哪里假，但会立刻觉得"这是拼的"。稣文原话：**「很多人觉得 AI 感强最大的问题不是人物而是光，因为真实摄影里阳光、环境反射、阴影关系都是统一的」**（V14）。

这一条不能靠"看着还行"来判断——**把两镜并排看，光源方向一左一右，就是废的**，不管画面多好看。

## 二、默认：大多数情况该做

### ① 遮挡再露出

适用：门店门口、街道、商场、有人流动的公共空间。

```
画面：前景有行人走过遮挡镜头，遮挡结束时人物已站定在画面中央
```

要点：**遮挡物必须在动**。静止挡住就变成糊画面，不是真实感。

### ② 手机对焦感

适用：手持感强的镜头、顾客视角。

```
画面：起始虚焦，0.5 秒内焦点落到人物面部，背景保持轻微虚化
```

要点：**只用在 1–2 镜**。每条都加对焦，比不加更假。

### ③ 前景短暂遮挡

适用：产品特写、人物正面。

```
画面：镜头前有植物叶片从画面右缘扫过，持续约 1 秒后移出
```

要点：一闪而过，别一直挡着。15 秒以内的商家单慎用——时长太短，观众还没意识到就没了。

## 三、可选：看片型，不加也行

### ④ 24 帧运动模糊

适用：跑步、快走、快速动作。

```
参数：24 帧，人物肢体有轻微运动模糊
```

这是**参数不是提示词**，取决于平台支不支持。静态镜头加了反而脏。

### ⑤ 微动态

适用：慢节奏氛围镜、品牌片。

```
画面：动作幅度极小，只有发丝和衣角轻微摆动，背景草地随风缓动
```

稣文的用法是靠微风吹草地、瓢虫振翅这种微动态给呼吸感（V02）。

**商家单基本用不上**：15–30 秒的片子节奏快，微动态会显得拖。

## 四、商家短视频实际只用三条

| 手法 | 商家单 | 理由 |
|---|---|---|
| 光影自洽 | ✅ 必须 | 不分片型 |
| 遮挡再露出 | ✅ 优先 | 门店门口天然有人流 |
| 手机对焦感 | ✅ 用 1–2 镜 | 手持感，像顾客自己拍的 |
| 前景短暂遮挡 | ⚠️ 慎用 | 时长太短，一闪就没了 |
| 24 帧运动模糊 | ⚠️ 看平台 | 很多入口不支持改帧率 |
| 微动态 | ❌ 不用 | 节奏对不上 |

**稣文有 6 条，商家单实际能用 3 条。** 他是品牌 TVC 的量级（3 天 / 一条），不能整套搬。

## 五、不要写这些词

```
❌ 4K 超清 / 真实拍摄 / 电影级画质 / 大片质感 / 高细节
```

稣文原话：**「不是因为我一直在写'超清 4K 真实拍摄'的提示词，而是我尽量按照真实的拍摄逻辑去设计这个画面」**（V12）。

真实感来自**摄影机为什么会动**，不是形容词。这类词占位置不产生效果，还会挤掉真正有用的细节描述。

## 六、怎么和现有字段配合

| 现有字段 | 加什么 |
|---|---|
| **光线** | 不写"自然光""柔和光"，写**光源方向 + 色温**："主光来自左上方窗户，色温偏暖" |
| **镜头运动** | 每条手法本质都是在改"为什么动"："镜头随行人走过短暂遮挡" |
| **负面约束** | 加一条："无 4K/超清/电影级等形容词" |
| **镜头卡** | 加一行 `本镜手法：遮挡再露出`，生成后能对照 |

镜头卡加那一行的作用：生成出来没有遮挡，能判断是**提示词没生效**还是**模型没做到**，而不是笼统地说"这条不好看"。
