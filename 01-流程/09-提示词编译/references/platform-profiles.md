# 平台条目

用于多平台适配。**这里没有预填任何平台规格**:生成式 AI 的功能和限制更新很快,凭记忆填写容易出错。条目只在核实后写入,并带来源和日期。

## 使用规则

1. 要为某个平台适配提示词时,先找该平台的条目。
2. 没有条目、核查日期距当前日期超过 90 天，或用户说平台更新了：将相关能力标为 `待核实:具体能力` 并重新核实；重新核实前不沿用旧规格作为当前事实。
3. 核实方式:
   - 有联网能力:查官方文档/入口页/更新说明,优先官方来源。结论标 `来源写明`，并记录来源链接与核查日期；官方文档是来源类型，不另作证据标签。
   - 无联网能力:请用户贴入口页的参数说明或截图。记录入口、模型/版本、可见的账号或地区限制、截图日期；对应结论标 `来源写明`，注明 `来源：用户提供的入口截图/文字（日期）`。截图未显示的字段仍标 `待核实:具体字段`。
   - 用户自己实测得出:将实测观察标 `来源写明`，并记录 `来源：用户实测`、平台/模型/入口、日期和测试条件；由观察推出的解释另标 `材料推导`，未复现的仍标 `待核实:需要复现`。
4. 条目中任何一栏没核实过，使用 `待核实:具体字段`。**不允许推测填入。**
5. 同一平台有多个入口(网页、App、API、第三方聚合)时,分别建条目,因为功能可能不同。

复制后填写,每个平台/入口一份。

### 豆包｜豆包 App 与 Seedance API 必须分开

- **核查日期：** 2026-11-02
- **来源：** 豆包官方[模型备案说明](https://www.doubao.com/legal/instructions)确认 App 内有视频生成模型；字节跳动 Seed 官方 [Seedance 2.5](https://research.doubao.com/zh/seedance2_5)；火山引擎官方 [Seedance 2.5 技术/模型说明](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)、[提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)、[创建视频任务 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)
- **证据标签：** `来源写明`（豆包官方页面确认 App 内视频生成；下述详细参数主要属于火山引擎 Seedance 2.5 模型/API，不可直接当作豆包 App 当前 UI 参数）。
- **豆包 App 当前入口：** 当前 App 选择的模型、可用时长、画幅、音频、参考数量和负面输入框均标 `待核实:豆包 App 当前入口选项`。需要用户提供当前入口截图/选项后再形成 App 专用档案。
- **Seedance 2.5 API 模型级输入：** 文本、图像、视频、音频可组合参考；官方模型文档列出文生、首帧/首尾帧图生、多模态参考、视频编辑和延长。API 可用角色字段/素材 URL 或素材 ID，具体按官方任务类型。
- **Seedance 2.5 时长：** API 模型页列 4–30 秒；版本/任务类型可能锁定或继承时长，必须按具体 task 检查。
- **画幅/分辨率：** API 文档列比例 21:9、16:9、4:3、1:1、3:4、9:16、adaptive；支持分辨率/比例随模型和任务而变。编辑、首尾帧、延长等任务可能自动锁定输入比例。
- **音频：** Seedance 2.5 支持音视频联合生成与音频参考；API 有 `generate_audio` 控制。不要把 API 参数名当成豆包 App 字段。
- **参考素材：** Seedance 2.5 API 文档列 50 项上限：最多30图、10视频、10音频；模型/任务对音频单独输入及参考素材总时长有区别。以该模型版本的 API 文档为准。
- **负面提示词字段：** 指南说明可在正文中用反向描述控制字幕/音频，例如要求不要字幕或不要 BGM；本次未确认专门的独立 `negative_prompt` 参数。不要把正文约束说成独立字段。
  - **⚠️ 2026-11-04 实测推翻：** 正文写"不烧录字幕""后期单独加字幕"，成片仍然出字幕。**反向描述对字幕无效**（至少在该入口）。改为：① 优先找平台的字幕开关；② 提示词里**一次都不出现"字幕"二字**，改成正向描述"画面干净、无文字图形"；③ 台词从画面描述里剥离到音频段。详见 `on-image-text.md`。
- **提示词语法：** Seedance 2.5 API 指南给出按上传顺序引用 `@图片N/@视频N/@音频N`、以及 `{}`台词、`()`音乐、`<>`音效、`〖〗`字幕等正文约定；仅用于该官方 API 指南覆盖的模型/入口，不推断豆包 App 使用相同语法。
- **适配建议：** 若用户在豆包 App，先按 App 屏幕上的模型与控件适配；若明确使用火山引擎 API，再使用本节 Seedance 2.5 规格和语法。

### MiniMax 海螺｜MiniMax-H3（第三方聚合入口，V2 视频格式）

- **核查日期：** 2026-11-03
- **来源：** 用户本机实测（经第三方聚合站 `api.lk888.ai` 的 `/v2/video_generation` 提交，MiniMax 官方 V2 视频格式透传）；时长与参考音频限制来自实测报错原文。**不是官方文档核对结果**，换入口/换模型版本后需重核。
- **证据标签：** `来源写明`（实测报错与成功记录）/ `材料推导`（由现象推出的解释）

#### 能力

- **输入方式：** 文生、多参考图（实测 2–3 张可用）、参考音频；首尾帧与视频续写 `待核实:当前入口是否支持`
- **单次生成时长：** 整数 4–15 秒（入口侧规则）；实测请求 5 秒，成片 5.26 秒
- **画幅与分辨率：** 9:16 / 1080P（实测）；其他画幅 `待核实:可选值`
- **帧率：** 实测输出 24fps
- **是否生成音频：** 是，可生成台词。给参考音频时既能"复用整条音轨"，也能只当**音色参考**由模型新说台词（两种都实测通过）
- **参考音频上限：** **单条不超过 15 秒**。实测 18.0 秒被拒，报错原文：`参考音频1时长 18.0 秒过长，最长 15 秒，请剪辑后重试`
- **参考图/视频语法：** 走参考图列表传本地文件，正文用 `<Picture N>` / `<Subject N>` 指代；没有官方语法文档，标签体系来自 MiniMax 官方提示词格式
- **负面提示词字段：** 无独立字段；负面约束写进正文（实测有效）
- **提示词语言偏好：** 英文正文 + 台词保留原语言（中文台词写 `<d>[Chinese] …</d>`）

#### 已知限制与注意

- **多视角角色设定图容易被读成多个人。** 三视图/五视图必须在 `<Subject N>` 里写明"同一个人从 N 个角度拍的 N 次，不是 N 个人"，否则会生成群像或换脸。
- **固定机位仍有缓慢漂移。** 实测 5 秒固定镜头，背景模板匹配显示缩放恒为 1.000（没推没拉），但整体位移约 12px / 1920px（≈0.6%）。要绝对锁死需后期校正。
- **主体居中会遮挡背景文字/标识。** "人物站正中央"和"校名居中"物理冲突，交付前要确认哪个优先，或用站位前后关系错开。
- **直出音频偏响。** 实测成片真峰 -0.3 dBFS、整体 -13.3 LUFS，平台转码易削波；交付前过 `loudnorm` 到 -14 LUFS / TP -1.5。
- **口播起音时刻不可控。** 两次反向实测：写「0.4 秒开口」→ 实际 0.68 秒；写「约 0.70 秒开口，允许自然起音」→ 实际 **0.05 秒**。两个方向都不准，说明模型不参考这个数。要精确留白只能事后剪，或走 `fully_copy` 让音频自带前置静音、画面跟着等。
- **参考音频要自己剪。** 交付包里的整段口播常超过 15 秒，用分句文件拼接更稳；拼接时多个间隙不要复用同一个 `anullsrc` 输出，会被 concat 重复拉长。

#### 适配注意

- 与平台中立版相比：需要补 `<Subject N>` / `<Picture N>` / `<Audio N>` 标签定义，`summary` 开头声明素材锁定。
- 需要拆分或改走实拍/后期的情形：一镜内跨场景+边走边说+多句台词，失败率高，建议拆镜或改用音频驱动写法。

## 平台中立版本的写法

没有已核实条目时,写平台中立版本:

- 只用所有平台都能理解的自然语言:主体、动作序列、景别、机位、光线、材质
- 不写任何平台专有参数、触发词、特殊语法
- 在提示词下方列出 `待核实:当前入口时长`、`待核实:画幅`、`待核实:参考图用法`、`待核实:负面字段`、`待核实:音频` 清单
- 如果用户要立刻投入使用,告知哪些处可能需要在入口里手动设置

## 多平台同步

同一个镜头给多个平台时:

1. 先写核心提示词(平台中立)
2. 再按各平台条目生成适配版
3. 每个适配版后列出"相对核心版的差异"
4. 检查含义一致:动作、构图、台词、出点不因适配而改变
