# 参考图里的文字怎么处理

> **一句话：模型不会复制文字，只会重绘字形。**
> 你给它的参考图里有一张写着「特级和牛」的卡片，它不会把那四个字搬过来，它会画四块看起来像字的形状。

---

## 症状

参考图（九宫格、产品图、实拍截图）里带有文字——菜品卡片、价签、招牌、菜单、包装标签。

生成的视频里，那个位置确实出现了文字，但**错版**：字形扭曲、笔画粘连、顺序错乱、变成不存在的字。

---

## 为什么「强调参照原图文字」会适得其反

常见的直觉是：既然模型没照着写，那我强调一句「一定要参照图片里的文字字样」是不是就好了。

**不会，会更糟。**

| 你以为的指令 | 模型理解到的 |
|---|---|
| 参照原图文字，不要错版 | 这个位置有一块文字形状，**要画得更明显、更用力** |
| 不要出现乱码 | 出现乱码（否定词在正向提示词里被激活） |
| 准确复刻「特级和牛」 | 画四个中文字形的图案 |

模型没有「文字复制」这个能力维度。它只有「文字生成」——根据上下文概率画出一个像字的形状。**你越强调，它生成得越用力，错得越离谱。**

而且「错版」这个词对它没有意义，它不知道什么叫版。

---

## 三条路，都绕开模型写字

### 路线 A：取景避开（首选，成本最低）

**做法**：构图里不让带字的物体成为主体或焦点。中景、边缘、被遮挡、只露一角。

**提示词写法**：
```
中景，人物在画面右侧，桌上餐盘位于画面左下角、部分出画。
景深较浅，背景虚化。
```

**适用**：文字不是卖点，只是场景的一部分。

**准确度**：100%（画面里没有字，就没有错版）

### 路线 B：让它虚焦（次选，最自然）

**做法**：把带字物体放在焦外，虚到读不出。

**依据**：本 skill 判档条件 3 的「不算」清单里明确写了——**背景里虚焦到读不出的文字，不算商业文字**。这是合法的绕开路线。

**提示词写法**：
```
浅景深，焦点在筷子和肉片上，背景餐牌完全失焦，只能看出色块。
```

**适用**：需要真实环境感，但文字内容不重要。

**准确度**：100%（读不出就不算字）

### 路线 C：后期贴回（必须清楚可读时唯一可行）

**做法**：
1. 生成一版**没有文字**的画面（该位置为空或模糊）
2. 从原图裁出文字区域，在剪辑软件里做跟踪贴图或直接合成

**提示词写法**：
```
餐盘上的卡片为纯白色空白卡片，表面无任何文字或图案。
（后期会在该位置叠加原卡片内容）
```

**适用**：文字承载商业信息必须准确——品牌名、价格、标签、资质。

**准确度**：100%（原图像素级复用）

**代价**：需要剪辑合成，有透视/跟踪成本。跟踪贴图需要软件支持。

## 怎么判断走哪条

```
这张参考图里的文字，看错了会不会造成商业后果？
├─ 不会（装饰、氛围、读不出）
│   ├─ 能不能不进画面主体？ → 路线 A
│   └─ 不能，但可以虚化？   → 路线 B
└─ 会（品牌名、价格、标签、资质）
    └─ 必须清楚可读 → 路线 C（后期贴回）
```

**这个判断和判档条件 3 是同一把尺子**：问一句「这字错了会不会造成商业后果」，不会就不算，会就必须后期。

## 错误写法对照

### ❌ 错误 1：要求复刻

```
参考图中的卡片上有"特级和牛"四个字，请准确复刻这四个字，不要错版。
```

**结果**：四个字被画成四个像字的形状，笔画错乱。

### ❌ 错误 2：要求避免乱码

```
卡片上的文字不要出现乱码。
```

**结果**：「乱码」被激活，生成更混乱的字形。

### ❌ 错误 3：给了文字内容但没说怎么办

```
画面：M级和牛盘，旁边有写着"特级和牛"的卡片。
```

**结果**：模型尝试写出这四个字，错版。

### ✅ 正确 1（路线 A/B，不要字）

```
画面：M级和牛盘特写，浅景深，焦点在肉片纹理上，
旁边卡片位于焦外，只呈现为浅色矩形色块，无可辨文字。
```

### ✅ 正确 2（路线 C，留空白位）

```
画面：M级和牛盘特写，旁边立着一张纯白空白卡片，
卡片表面无任何文字、图案或印刷内容。
```

后期再把原图的「特级和牛」贴上去。
