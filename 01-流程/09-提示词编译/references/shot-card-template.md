镜头多时使用。精简版也必须覆盖主文件列出的全部必填字段；仅可把字段写得紧凑，不得删掉参考职责、负面约束、声音、证据标签或模型时长/剪辑时长的区分。用户要求完整交付时使用完整版。

## 五、示例(仅示范格式,内容为虚构)

```
### 镜头 2
- 来源时间码:00:03–00:06
- 剪辑目标时长:3 秒
- 模型生成时长:待核实:当前入口可选时长
- 制作路线:图生视频

**首帧构图**
主体位置:画面右三分之一,木桌后
朝向/视线:身体朝左,视线落在桌面中央的杯子上
起始姿势:双手分放桌面两侧,肘部微弯
道具位置:白色陶瓷杯在桌面正中,杯口冒热气
前景 / 中景 / 背景:前景虚化的窗框 / 桌与人物 / 浅色墙面
焦点:杯子

**主体与连续性锚点**
(角色A:参考图 A-正面 控制面部与发型;深灰针织衫;白色陶瓷杯;侧窗柔和日光自画面左侧入)

**独立视频提示词(平台中立)**
室内木桌旁,角色A身体朝左,低头看着桌面中央冒热气的白色陶瓷杯。她先抬起右手握住杯柄,再把杯子缓缓端起到胸前,视线随杯子上移,嘴角不动。中景,平视,机位固定。焦点在杯子,背景浅色墙面轻微虚化。侧窗日光自左入,杯沿有柔和高光,热气向上飘散。

**声音**
- 台词:无
- 环境音:室内安静底噪,杯底离桌的轻响
- 音乐:脚本未指定

**屏幕文字**
- 无

**负面约束**
- 杯子全程只有一个,颜色保持白色 → 正向描述 + 后期质检
- 右手手指数量正常、握杯姿势不变形 → 后期质检

**出点与转场**
- 最后姿态:杯子停在胸前,视线在杯子上
- 切点:杯子停稳的瞬间
- 带入线索:杯底离桌的轻响延续到下一镜

**规则溯源**
- `来源写明`:端杯动作、白色陶瓷杯
- `材料推导`:右手、胸前停点、机位与景别
- `待核实:角色是否说话`:脚本未写;本示例按无台词处理,正式项目需确认
```

## 六、三栏证据表最小范例

| 来源写明 | 材料推导 | 待核实 |

| `来源写明`:镜头 3 台词“……”（脚本 00:08–00:11） | `材料推导`:为留说话停顿，将剪辑目标时长设为 4 秒 | `待核实:当前入口最长时长`:目标模型是否支持 4 秒单镜 |
