# 经验库

本文件中的 `待验证假设` 与 `已确认规律` 是**经验库内部状态**，只表示经验条目的沉淀阶段，不是全局证据标签。结论证据仍按主文件标签写为 `来源写明`、`材料推导` 或 `待核实:具体事项`。

记录有实际生成结果支撑的观察，避免把猜测或平台宣传写成经验。

## 规则

- 只记录实际生成且有人查看复核的结果。
- 每条需带平台/模型/入口、现象、改动、结果、证据标签与适用范围。
- 单次现象先作为“候选经验”提供给用户审阅；只有用户回复“记”后，才写入本文件的“待验证假设”。
- 相同适用条件下至少两次方向一致的复现，并经用户确认后，才可将条目状态改为“已确认规律”。这两个名称是经验库内部状态，不是证据标签。
- 规律必须写明适用范围，不外推到其他平台或镜头类型。
- 被推翻的条目不删除；标注 `已被推翻` 并写明原因和日期。平台更新后标注 `可能过期` 并注明日期。

## 候选经验格式

候选先交用户审阅，不直接写入经验库。必须基于真实生成结果；没有生成结果时不提出候选。解释仍属推断时标 `材料推导`，需要重复验证的内容标 `待核实:需要复现`。

```markdown
### 候选 L-<编号> <一句话观察>
- 平台 / 模型 / 入口:
- 适用镜头与条件:
- 预期与实际差异:
- 本轮改动:
- 观察到的结果:
- 证据标签:来源写明 / 材料推导 / 待核实:需要复现
- 建议状态:待用户确认是否记入“待验证假设”
```

## 正式条目格式

```markdown
### L-<编号> <一句话标题>
- 日期:
- 平台 / 模型 / 入口:
- 类型:视频 / 图片 / 图生视频 / 其他
- 现象:
- 原提示词片段:
- 改动:
- 结果:
- 证据等级:单次 / 多次复现(次数:)
- 证据标签:来源写明 / 材料推导 / 待核实:具体事项
- 适用范围:
- 状态:待验证假设 / 已确认规律 / 可能过期 / 已被推翻
```

## 待验证假设

### L-01 多视角角色设定图必须在定义里声明"同一人 N 次"，否则会被读成多人

- 日期: 2026-11-03
- 平台 / 模型 / 入口: MiniMax-H3 / `api.lk888.ai` `/v2/video_generation`（第三方聚合，V2 格式透传）
- 类型: 图生视频 / 参考生视频
- 现象: 参考图是五视角角色设定图（同一人五个角度），若只写"shown in <Picture 1>, a five-view character turnaround"，模型存在把五个角度读成五个人的风险，表现为群像或换脸。
- 原提示词片段: `<Subject 1> is the middle-aged Chinese woman shown in <Picture 1>, a five-view character turnaround: ...`
- 改动: 在定义里补一句"同一人多次，不是多个人"，并按图逐项描述五官、发型、眼镜、服装。
- 结果: 5 秒单人口播镜头中，人物形象与参考图一致，无换脸、无第二人入画。`来源写明`（本人复核成片帧）
- 证据标签: 来源写明
- 适用范围: 使用多视角/多姿态角色设定图做参考的图生视频；其他平台是否同样需要此声明，`待核实:需要复现`
- 状态: 待验证假设

### L-02 把克隆音频当时间轴主轨、表演锚到秒，比"先写动作再贴音频"更稳

- 日期: 2026-11-03
- 平台 / 模型 / 入口: MiniMax-H3 / `api.lk888.ai` `/v2/video_generation`
- 类型: 视频（含口播、音色参考）
- 现象: 旧写法先描述人物走、说、笑，再把音频当参考轨复制；时间轴越长（多句台词+跨场景），口型与节奏越对不上。原因是模型先生成表演、音频后配。
- 原提示词片段: `She walks at a natural pace and says, <d>[Chinese] …</d>` + 音频只在 retention 段出现
- 改动: ①`summary` 开头声明四份素材锁定；②`<Audio N>` 定义里写清句数、句间间隔、总长；③表演锚到秒（`At 00:03.541 her lips close … through the 0.34-second gap`）；④补 `she never speaks outside <Audio N>`。
- 结果: 台词设定窗口 0.4–3.5 秒，成片实际语音的起止与目标窗口的偏差,数值见 `platform-profiles.md` MiniMax-H3「已知限制 · 口播起音时刻不可控」;句前后全静音，无多余声音、无第二个说话人。`来源写明`（转录 + silencedetect）
- 证据标签: 来源写明（实测结果）/ 材料推导（因果解释）
- 适用范围: 单人口播、固定机位或稳定运镜；复杂多动作镜头尚未验证
- 状态: 待验证假设

### L-03 固定机位仍有约 0.6% 的缓慢平移漂移，无缩放

- 日期: 2026-11-03
- 平台 / 模型 / 入口: MiniMax-H3 / `api.lk888.ai` `/v2/video_generation`
- 类型: 视频
- 现象: 提示词明确写了不推、不拉、不摇、不变焦，成片肉眼看似静止，实际背景在缓慢位移。
- 原提示词片段: `The camera never moves: no push in, no pull out, no pan, no tilt, no zoom, no cut and no reframing`
- 改动: 无（提示词已写到最严）
- 结果: 以背景门区为模板做二维匹配（含缩放搜索），缩放恒为 1.000,整体位移非零不可忽略,具体数值见 `platform-profiles.md` MiniMax-H3「已知限制 · 固定机位仍有缓慢漂移」。`来源写明`（本人实测）
- 证据标签: 来源写明
- 适用范围: 5 秒单镜、静态背景；更长镜头是否累积漂移，`待核实:需要复现`
- 状态: 待验证假设
