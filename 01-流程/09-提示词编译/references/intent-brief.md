# 模式 A:想法 → 脚本

提示词不准,多数时候是想法本身没说清。本模式先把想法变成可执行的简报,再写脚本。脚本定稿后才进入模式 B。

如果用户手里只有参考图/参考视频、没有想法描述,不走本模式,改走 SKILL.md 的模式 D。

## 1. 先看已有材料

用户已经给出的信息(文字、图片、参考片、品牌资料)先全部读完、抽出来,再决定问什么。不要让用户重复回答已经说过的内容。

## 2. 意图澄清清单

按重要性排序。一次最多问 3 个,附默认值,用户可以回答"都按默认"。

**必须明确(影响整体设计)**
1. 成片用途与平台:投放在哪里(短视频、详情页、线下屏、社媒封面)?
2. 画幅与目标时长
3. 主体:是谁/什么产品/哪个品牌?有没有必须出现或必须避免的元素?
4. 核心信息:观众看完应该记住或做的一件事,以及支撑它的真实事实。没有任何真实素材时,不直接写口播,先给 2–3 个创意方向,各自写明需要用户提供的事实

**强烈建议明确(影响风格和一致性)**
5. 参考:有没有想接近的片子、图、风格?"像这个,但不要它的 X" 比形容词有用
6. 情绪与节奏:快/慢,轻松/克制,哪里是高点
7. 是否有真人、实拍或数字人,还是全部生成
8. 声音:有无台词、旁白、音乐;是否需要口型同步。有口播时:谁在说、对谁说、什么场合,最好附 1–2 段说话人真实说过的话(语音转文字、聊天记录)作语感样本

**可以先用默认(之后再调)**
9. 色彩倾向、镜头语言偏好
10. 字幕与屏幕文字
11. 品牌合规要求(AI 标识、广告法用语、素材授权)

用户说不清时,不要追问形容词,改给**2–3 个具体可选方案**让用户挑(例如"A:近景特写快切;B:中景长镜头慢推"),选择比描述容易。

## 3. 意图简报模板

澄清后先输出简报,让用户确认后再写脚本。

```
# 意图简报 v1
- 项目:
- 用途与平台:
- 画幅 / 目标时长:
- 主体与必须元素:
- 必须避免:
- 核心信息(一句话):
- 参考与"像什么/不像什么":
- 情绪与节奏曲线:(开头 → 中段 → 高点 → 收尾)
- 制作路线倾向:(全生成 / 生成+实拍 / 数字人 / 后期补字)
- 声音:(台词 / 旁白 / 音乐 / 无)
- `待补:用户补充信息`:
- 已作假设:
```

## 4. 脚本格式

用户确认简报后写脚本。脚本是后续提示词卡的**唯一事实来源**,所以格式要可被逐镜头引用:

```
# 脚本 <标题> v<版本>  (画幅 / 总时长 / 镜头数)

## 镜头 1  [00:00–00:03]  路线:<生成/实拍/数字人/后期>
画面:(可见内容,一个主要动作)
台词/旁白:(逐字,标说话人;无则写"无")
说话窗口:(秒;扣掉静止/动作/停顿。台词字数 ÷ 窗口 = 字/秒)
声音:(环境音 / 音乐)
屏幕文字:(原文 + 时间;无则"无")
备注:(来源事实、品牌要求、风险)
```

写脚本时注意:
- 每个镜头只放一个主要动作;时长要给台词留出念完的时间(中文朗读速度因人而异,标出紧的地方,请用户读一遍)
- 只写有依据的品牌主张和产品事实；来源有写但未外部核实的标 `未独立核实`；事实依据缺失时标 `待核实:事实依据`，不得自行补写
- 钩子、反转、揭示单独成镜头或节拍,便于之后精确控制
- 标出哪些镜头对 AI 生成来说风险高(多人互动、精确文字、复杂手部动作、长对白口型),并提出备选路线

### 口播写法

适用:模式 A 写脚本,或用户明确要求润色/重写口播。用户已定稿的台词不适用,逐字保留。

1. **先定说话人,再写词**:谁在说、对谁说、什么场合。有真实说话样本,就以样本的句长、口头词、语气为准;没有样本,交付里标 `待补:语感样本`,不假装已对味。
2. **一条口播只放一个核心信息**,用具体的画面或细节说,不用概括性形容词和文艺比喻。
3. **口语规则**:句子短且长短不齐;连接用"然后/所以/你看/就是",少用"因此/此外/然而";可以省主语、可以有半句和自我修正,但每一处都要有表演理由:能说出这句废话在替谁服务(比如"就是说"是在给自己争取想词的时间,重复前半句是在强调给对方听)。说不出来的,删掉——不为"像人"而堆口头禅。
4. **AI 腔黑名单**(出现就重写):"不仅……更……"、"在这个……的时代"、"让我们……"、"赋能/打造/致力于/匠心"、三连排比、结尾升华句、成对对仗的金句。
5. **两遍写法**:第一遍只写信息要点;第二遍假设说话人看着要点即兴讲,保留信息、不保留句式。
6. **说话窗口与语速**:每句标说话窗口秒数,按主文件的语速规则核对,留出换气点。
7. **不新增事实**:口语化不能带进价格、优惠、承诺、"最/第一"这类新宣称;没有事实依据的卖点只写画面,不写断言。
8. **念读测试**:写完请真人出声念一遍,卡壳的字记下来改。没念过的,标 `待补:真人念读`,不说"已自然"。

## 5. 定稿

用户明确确认"脚本定稿"后,锁定版本号,转入模式 B。定稿后的改动按新版本处理,并在版本锁定里记录变更点。
