# 干净版分镜表

> 给下游**生成**环节用（本技能的默认下游是 AI 生成，不是实拍）。
> **只留执行要的信息**：镜号、时长、画面、台词、字幕、音效、生成备注。
> 诊断结论、改动理由、原句对照一律不放这里——那些属于诊断文档，混进来下游会看花眼。

> **台词与字幕必须分列。** 台词是角色用嘴说的（要口型、要配音），字幕是后期叠上去的（不进口型、不进画面）。
> 合成一列，下游会把字幕当台词去生成口型，或者把台词烧成字幕。这是 AI 生成最常见的一类返工。

## 三条填写规则

1. **画面描述要能直接执行**。写"她举着夹子停在半空，不敢下"，不写"表现出犹豫"。
2. **台词只写要说的字**，完成态的语气和表演提示写进生成备注；**字幕只写要叠的字**，不留字就填"无"。
3. **镜号连续不跳号**，下游按镜号逐条编译提示词，跳一个号就接错一镜。
4. **一行一镜，时长精确到秒**。时长合计必须等于成片时长，差一秒都算表错了。

## 生成备注怎么写

备注列给生成环节看，实拍时可以留空。四类信息：

| 类别 | 写什么 | 例（通用示意） |
| --- | --- | --- |
| **景别与运镜** | 特写／中景／全景，固定／推／摇 | 中景固定，人物占画面右 1/3 |
| **主体动作** | 这一镜里人／物在做什么 | 夹子举到一半停住，迟疑两秒 |
| **光线与质感** | 色调、光源、颗粒 | 暖调，侧逆光，胶片颗粒 |
| **规避项** | AI 容易崩的地方，明确要求避开 | 只拍小臂不拍手；只拍肩与桌面；不拍正脸 |

**规避项是 AI 生成的关键。** 手部、正脸、快速转身、多人同框，这几处崩得最多。与其生成十次挑一次，不如一开始就不让它们进画面。

上面的"例"是写法示意，不是案例内容。真实案例见下节，那部分有出处。

## 交给下游时怎么接

这张表是**提示词的原料**，不是提示词本身。下游按镜号逐条编译，映射关系：

| 本表列 | 进提示词的哪个位置 |
| --- | --- |
| 镜号 | 作为该条提示词的唯一标识，**必须带**，否则十条提示词分不清对应哪一镜 |
| 时长 | 生成时长参数 |
| 画面 | 主体 + 动作 + 运镜 + 场景光线 |
| 台词 | 对白字段（原语言原句，不改写） |
| 字幕 | **不进提示词**，走后期叠加 |
| 音效／音乐 | 环境声字段 + 配乐字段，两层分开 |
| 生成备注 | 规避项 = 负面约束；景别运镜 = 补充描述 |

字幕不进提示词这一条最容易错。烧进画面的字（价签、招牌、门牌）要单独说明走"原图直出"还是"锁首帧保留"，不能混在字幕列里，也不许写"后期贴"。
