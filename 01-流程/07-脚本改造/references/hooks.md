# 九钩归三引擎

市面上的"九大爆款钩子"其实是三类心理机制的不同说法。分类的意义只有一个：**每类引擎对应不同的素材要求。** 选错引擎，等于承诺了手上没有的东西。

## 三类引擎

### 一 · 信息落差型

覆盖：好奇钩、权威钩、经验钩。

观众的心理动作："他怎么知道我不知道的。"

| 项 | 内容 |
| --- | --- |
| 必须拍到的素材 | 内幕细节、资质与数字、亲历事故、独家工艺 |
| 适合的目的 | 曝光、信任、涨粉冷启动 |
| 常见失败 | 号称揭秘却拿不出细节，只能给结论 |

句式骨架（自行填品类，不要照抄整句）：

- 数字前置 + 反常识：`我干这行 X 年，只见过 X 个人做对这一步。`
- 内幕口吻：`这个行业的 X，我今天说一次。`
- 亲历代价：`我花 X 万买的教训，就是这一步。`
- 资质兑现：`X 年、X 家店、X 个客户，可以查。`

### 二 · 风险规避型

覆盖：警示钩、争议钩。

观众的心理动作："我是不是正在做错。"

| 项 | 内容 |
| --- | --- |
| 必须拍到的素材 | 反例现场、价格对比、踩坑实录、拆解过程 |
| 适合的目的 | 曝光、信任、冲评论 |
| 常见失败 | 只喊"别被坑"，拿不出一个具体反例 |

句式骨架：

- 判断条件：`如果你手上这个用了超过 X 年，先别换。`
- 拆穿对比：`同一样东西，差 X 倍价，差在哪我给你拆开。`
- 唱反调：`都说不 X 不专业，我偏不 X。`
- 三问清单：`做这件事之前，先问清楚这三个问题。`

> 争议钩衰减最快——同行全在用，观众三秒就认出是话术。冲流量可以，长期靠它养不活账号。

### 三 · 结果诱惑型

覆盖：行动钩、紧迫钩、结果钩、情感钩。

观众的心理动作："我也想要 / 我也怕变成那样。"

| 项 | 内容 |
| --- | --- |
| 必须拍到的素材 | 前后对比、真实反应、场景实拍、使用瞬间 |
| 适合的目的 | 团购、种草、转化 |
| 常见失败 | 只描述结果不展示过程，观众不信"变好"这件事 |

句式骨架：

- 场景绑定：`X 点下班的人，来这儿 X 分钟就能吃上。`
- 前后对照：`做之前和做之后，你自己看。`
- 门槛降低：`第一次来也不用会，坐下等就行。`
- 共情落点：`我也当过消费者，知道被套路什么滋味。`

## 目的 → 引擎 → 收口

| 目的 | 首选引擎 | 搭配 | 收口动作 |
| --- | --- | --- | --- |
| 曝光 / 上热门 | 风险规避、信息落差 | 冲突、好奇 | 提问引导评论 |
| 建立信任 | 信息落差（权威） | 信息、共鸣 | 引导关注 |
| 人设涨粉 | 结果诱惑（情感）、信息落差（经验） | 共鸣、幻想 | 悬念预告下期 |
| 团购转化 | 结果诱惑 | 利益、欲望 | 点击下单 / 囤券 |
| 效果种草 | 结果诱惑（结果） | 感官、欲望 | 同款体验引导 |

## 选引擎的顺序（与常见手册相反）

常见手册：先定钩子 → 套句式 → 填内容。

本技能：**先盘素材 → 反推能撑住哪类引擎 → 最后写钩子。**

理由：钩子是承诺，承诺不能凭空写。手上只有一段成品镜头，却写"90% 的人都被坑过"，第 8 秒就拿不出证据，完播率反而更差。

## 三类引擎的衰减速度

| 引擎 | 衰减 | 原因 |
| --- | --- | --- |
| 风险规避（警示、争议） | 最快，约 3–6 个月 | 同行密集使用，观众形成免疫 |
| 信息落差（好奇、权威） | 中，1–2 年 | 依赖行业信息差，信息差会消失 |
| 结果诱惑（结果、情感） | 最慢 | 落在人群层：怕什么、羞于承认什么 |

账号想活过三个月，不能只靠前两类。
