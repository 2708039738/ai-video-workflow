# 短视频与长视频脚本改造

## 立场（先读，决定一切后续动作）

1. **钩子是承诺，素材是兑现。** 没有素材支撑的钩子，第 8 秒一定塌，完播率反而更差。空头支票比不吹牛更伤人。
2. **规则用来判定，不用来把分数做好看。** 走 scorecard 十项时，第 5 项（8 秒兑现）和第 6 项（证据位）任一项为零，直接退回重写，不进入逐句修改；走长视频表时，看第 4 项（二次钩子）。
3. **不搬过期话术。** "谁懂啊／绝了／就离谱"属形式层，三个月过期，且一出现就等于告诉观众这是广告。网感写在人群层：观众怕什么、羞于承认什么、想在评论区说什么。

## 流程

### Step 0 · 读稿

- 分镜表要拿到**全部单元格内容**，不要只看结构预览——预览会截断长段落，漏掉的往往正是台词。
- 任何格式（docx／表格／图片／直接粘贴）都按当前环境可用的方式读取；读不全就请对方补纯文本，不凭预览猜内容。
- 记录：总时长、镜头数、每镜时长、每镜画面/台词/字幕/音效。
- 先把原稿的专业部分识别出来（AI 生成规避手法、镜头语言、音效设计），这部分后面一字不动。

> **下游前提：本技能服务的是 AI 生成片，不是实拍片。**
> 这条决定后面所有判断：证据位不能依赖"真实人物反应"（AI 造不出来，造了就是 B7 违规），
> 画面描述要写到能直接喂模型，生成备注是必填而不是可选。
> 如果这条片子确实是实拍或实拍+AI 混合，先说明差异再开工，不要默认套用。

### Step 1 · 判档与诊断

- **先判档，再打分。** 判错档，后面全错：
  - ≤ 60s → 主规则（本文件 + `scorecard.md`）
  - 60–120s → 主规则 + 中段二次钩子
  - > 120s → 换成 `scenes.md` 的长视频检查表，不要套 `scorecard.md` 那十项
  - 教程类／品牌形象片／纯产品展示 → **减配处理**（见 `scenes.md` 第一节减配表），不是不做，是少评几项
- 按档位打开对应检查表：S／M 档用 `references/scorecard.md`，L 档用 `references/scenes.md` 的长视频表。逐项打分，输出总分、失分项、一句话结论。
- 判定线：<14 分退回重写；14–15 定向返工；≥16 可发。走 scorecard 十项时，第 5、6 项任一为 0 无条件重写；走长视频表时，第 4 项（二次钩子）为 0 整条退回，重做中段。
- 结论必须区分两种病，二者改法相反，返工量差一个量级：

| 病名 | 症状 | 改法 |
| --- | --- | --- |
| **结构塌陷** | 中段连续多镜说同一件事，空转十几秒 | **删**：删镜头、压时长 |
| **证据缺失** | 大段口播全是形容词和名词短语，无一可验证 | **补**：插入证据段，不能只靠删 |

- 一个常见误判（scorecard 口径）：总分 16（≥可发线）但第 6 项为 0。这代表"话说得漂亮，但一句能验证的都没有"，仍须退回，按证据缺失处理。**两个数并存时以硬规则为准。**

### Step 2 · 定目的

- 从曝光／信任／涨粉／团购／种草里选且只选一个。
- 目的不唯一就拆条，不要叠加。原稿常把"爆款＋大促"写在一起，那是没定目的。
- 目的决定钩子引擎，见 `references/hooks.md`。

### Step 3 · 盘素材（含 AI 可做性）

- 先列手上有什么：真实数字、顾客反应、前后对比、店内素材、老板亲历、能呈现的画面。
- **素材决定钩子，不是钩子决定素材。** 手册的顺序是"先选钩子再填内容"，反过来才对。
- 缺什么明确标出（用 ⬜ 占位），不代填。

**每一项素材都要过一道"AI 做不做得到"：**

| 素材类型 | AI 能做的 | AI 不能做的（做了就是 B7） |
| --- | --- | --- |
| 产品外观 | 用真图驱动，外观可保持 | 改花纹、改文字、改结构 |
| 人物反应 | 可以生成，但**不能声称是真实顾客** | 真实评价、真实交易记录、真实回头率 |
| 使用场景 | 矿山、工地、厨房、仓库都能生成 | 真实门店内部（会和实际装修不符） |
| 过程演示 | 生到熟、铺到翻、拆到装，可行 | 需要精确计时的工序（如"三分钟出餐"） |
| 数据与参数 | **完全不生成** | 全部走后期字幕，绝不写进画面 |

判断口径一句话：**事实必须真，画面可以生成。** 凡是"事实"要靠生成的，一律标 ⬜ 让客户提供。

### Step 4 · 重排结构

- 四拍是 **≤60s** 的骨架。60–120s 仍用四拍，但中段必须插二次钩子；120s 以上按 `scenes.md` 的四关口重排，不要硬压成四拍——压了会丢掉未完成感，观众在中段就走。
- 四拍：0–3s 钩子 / 3–8s 兑现 / 8–13s 证据 / 13s–结尾 递进＋收口。
- 一条只打一个卖点，第二卖点出现就删或另起一条。
- 中段每 3–4 秒一次信息增量。连续两镜说同一件事，删掉多余的。
- 证据位必须是**能呈现的画面**（实拍或生成都算），且尽量前移到全片 1/3 处。素材没变、只挪位置，是零成本改动里最值钱的一条。
- 互动钩（可被回答的问句）放在 1/3–1/2 之间，不要留到结尾。
### Step 4.5 · 时长核算（按镜头类型算，不要一刀切）

**台词时长 ≠ 镜头时长。** 台词在音轨层，镜头在画面层，两者可以不同步。先给每镜标类型，再算：

| 镜头类型 | 算法 | 例 |
| --- | --- | --- |
| **A 纯口播**（人在说，无其他动作） | 字数 ÷ 语速 | 数字人口播、对镜头讲解 |
| **B 台词 + 动作**（边说边做） | **取两者较大值，不相加** | 边翻肉边说"七分熟谁说了算" |
| **C 纯动作**（无台词） | 动作节点数 × 1.2–1.8 秒 | 夹子被抽走、手停半空 |
| **D 空镜／转场／B-roll** | 0.5–2 秒，**不套台词公式** | 矿山碎石、产品特写 |
| **E 留白**（故意不说话） | 设计值，单独标注 | 吃完沉默两秒 |
| **F 台词跨镜** | 音轨连续、画面切，注明跨哪几镜 | 一句话念 5.6 秒，画面切三次 |

语速按片型取，不要写死 4.5：

| 场景 | 字/秒 |
| --- | --- |
| 平静讲解、招商口播 | 4.0 |
| 常规口播 | 4.5 |
| 探店、带货、信息流 | 5.5–6.0 |
| 情绪激动、喊话 | 3.5 |

两条底线：

1. **台词总时长 ≤ 全片 × 0.9**——留 10% 给没台词的画面，否则全片没有呼吸。
2. **单镜实际时长超过应占的 1.5 倍 = 注水**（10 个字本该 2 秒，排了 8 秒，多出的 6 秒是纯拖）。先砍台词，再砍镜头——砍镜头会伤结构。

填进干净版分镜表时，**每镜都要能反推出"这句话几秒"**，不能只在心里估。

### Step 5 · 改台词

- 前 3 秒禁形容词（超／很／特别／专业／正宗／高端），换成数字、对比或具体动作。
- **台词说情绪，画面说事实。** 画面能演出来的，台词不要再说一遍。
- 每句台词过三问：三秒能听懂吗／能原样转述给朋友吗／是不是在替观众下判断。
- 至少留一句**金句**——不需要解释、听完能直接讲给别人的那句。
- 逐句过 `references/line-fixes.md` 的六种病：形容词堆砌、同义重复、逻辑硬伤、自我陈述、感慨代替情绪、名词短语当卖点。改不动的先怀疑素材不够，别硬编。
- 其中「感慨代替情绪」最值得单独做：把感慨换成具体的恐惧或欲望——感慨只传递信息，不制造情绪。

### Step 6 · 收口与物料

- 收口三件套：动作 + 结果 + 现在做的理由，缺一不算收口。
- 禁用结尾：欢迎到店咨询／感兴趣私信／谢谢观看／求点赞关注。
- 产出三样配套：标题 3 版（悬念式、对比式、讲故事式各一）、封面主字 1 版（≤6 字）、置顶评论 1 条。写法与发布设置见 `references/platform.md`。
- 标题里的信息必须在片中出现，否则是骗点击，会掉完播。

### Step 7 · 交付

按此顺序输出，不要打乱：

1. 诊断（打分 + 结论）
2. 改动清单（每处：原句 → 改后 → 为什么）
3. 改后分镜表
4. 镜头级完整对照（哪些改写／删除／保留／新增）＋ 时长去向（删几秒、增几秒、压几秒）
5. 配套物料（标题 3 版／封面 1 版／置顶评论 1 条）
6. 需要客户确认的项（真实利益点等，留 ⬜，并写明不填的后果）
7. **原稿保留部分**——写明哪些一字未改、为什么
8. **干净版分镜表**——只留下游生成要用的字段，不带诊断、理由和改动说明。格式见 `assets/storyboard-clean.md`。
   必须带**镜号**（S01、S02…），下游按镜号逐条编译提示词，缺号会接错。

第 7 条（原稿保留部分）经常被忽略，但它决定客户敢不敢用这份稿：改稿的人如果连哪儿不该改都说不出来，客户会怀疑他只是在重写一遍。

第 8 条（干净版分镜表）是唯一给下游看的文件。诊断文档里混着原句对照和删除标记，拍摄／生成的人照着做，会把已经删掉的镜头也拍出来。

可视化可选：用 `scripts/compare_chart.py` 生成改前改后对照图，左右两条时间轴同刻度，色块高度即镜头时长。

## 硬规则速查

**A 输入闸门**

| 编号 | 规则 |
| --- | --- |
| A1 | 一条视频只对应一个目的，出现两个就拆条 |
| A2 | 先报清素材，零素材的钩子不用 |
| A3 | 人群写到"谁、在什么场景刷到"的粒度，写不到不开写 |
| A4 | 时长先定死，档位与判档一致：≤60s／60–120s／>120s |

**B 结构**

| 编号 | 规则 |
| --- | --- |
| B1 | 钩子承诺什么，8 秒内必须兑现；60s 以上放宽到前 1/4 |
| B2 | 前 3 秒出现形容词即重写 |
| B3 | 第 3 秒必须"跟我有关"：点人群、点损失、点好处，三选一 |
| B4 | ≤60s 四拍不塌，中间不留过渡句；60s 以上必须有二次钩子 |
| B5 | 证据 = 真实事实 + 可呈现画面。事实不可生成，画面可以；只有画面没有事实，算伪证据 |
| B6 | 一条只打一个点 |
| B7 | AI 生成画面不得虚构事实：顾客评价、使用效果、资质数据必须真，编出来按红线一票否决 |
| B8 | 证据位优先选 AI 能稳定产出的类型（产品特写、过程演示、场景空镜）；"真实人物反应"类证据在 AI 片中不成立，改用数据字幕或实拍补 |

**C 收口**

| 编号 | 规则 |
| --- | --- |
| C1 | 可回答的问句放在 1/3–1/2 处，不放结尾 |
| C2 | 收口三件套齐全 |
| C3 | 无指向的礼貌用语一律删 |

**D 红线（一票否决，不参与打分）**

| 编号 | 规则 |
| --- | --- |
| D1 | 绝对化与效果承诺：最／第一／保证／三天见效／稳赚 |
| D2 | 照搬他人原句：句式可借，词句必须重写 |
| D3 | 素材无授权：他人视频、无肖像同意的顾客正脸、商用盗用 BGM |

## 反模式

- ❌ 为了让分数好看硬凑——打分表次次满分就失去参考价值。够不着就写"这一项受素材限制，只能到 1 分"。
- ❌ 拿绝对数判成败（"1 小时破 5000 播放"）——不同赛道差十倍，改与账号自身前 10 条的中位数比。
- ❌ 把原稿的专业手法一起改掉——AI 规避、镜头语言、音效设计属于"不该动的部分"。
- ❌ 替商家编造利益点、价格、名额——没有就给 ⬜，让商家填。
- ❌ 用"评论区扣 1""点赞过千出下集"当互动钩——观众不会为博主的 KPI 行动。
