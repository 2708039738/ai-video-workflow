# 06 · 参考拆解

> 客户给了一条「就照这个做」的视频，或者你自己想学一条片。
> **这一段决定你的分镜有没有「可迁移的手法」。**
>
> ⚠️ **对标视频是可选输入。** 客户给就拆，不给就跳过这一环直接进 07——不要因为没参考片就卡住。

| | |
|---|---|
| **上一步给我什么** | 客户提供的**对标视频**（**可选**：有的客户给，有的不给），或你自己选的参考片 |
| **这一步交什么** | 镜头表 + 接点表 + 中文标注版 MP4 |

---

## 拆哪六层

| # | 层 | 问什么 |
|---|---|---|
| 1 | **景别** | 远/全/中/近/特，为什么用这个距离 |
| 2 | **角度** | 平/俯/仰/侧，机位在哪 |
| 3 | **主体动作** | 谁在动，动了几次，动作顺序 |
| 4 | **运镜** | 推/拉/摇/移/跟，还是固定。**注意区分主体移动和相机移动** |
| 5 | **景深** | 背景虚不虚，焦点在哪 |
| 6 | **切点与转场** | 哪里剪的、怎么接的、有没有声音桥 |

---

## 做什么

**① 先取帧，再看片**

不要用一张截图推断运动，也不要用每秒一帧推断快速转场。有运动的镜头至少比较前、中、后三个时刻。

**② 每镜写三句话**

> 看到什么 → 叫什么 → 给 AI 怎么说 / 真实素材怎么剪

三句话缺一句，这条拆解就没用。只写术语（「中景」「推镜头」）不算拆解。

**③ 切点单独建表**

每个切点记录：前镜结束状态、后镜开始状态、为什么在这里切、有没有声音衔接。

**④ 输出中文标注版**

把术语和解说烧在画面上，方便反复看。

---

## 过关

- [ ] 每镜都有**实际观察**，不是术语堆砌
- [ ] 切点是看过前后连续帧确认的，不是软件自动检测直接用的
- [ ] 区分了「主体在动」和「相机在动」
- [ ] 每条拆解都能对应到自己的分镜（不是拆完就放着）

**最重要的一条：拆解必须能被用上。** 拆完写进分镜的哪一镜，要标出来。

## 需要什么能力 / 用什么

| | |
|---|---|
| 能力 | 会看片（能说清一个镜头里发生了什么）；能读懂景别/角度/运镜 |
| 工具 | `annotate-video-language`（WorkBuddy，需要 ffmpeg）；没有工具就手动截帧 + 手写表 |

---

## 常见卡点

**用剧情摘要替代技术分析。**

「这个视频讲了老板创业的故事，很感人」——这是观后感，不是拆解。

拆解要回答的是：**第 3 秒为什么切了？这个镜头为什么用俯拍？**

另一个卡点：**拆得很细，但写分镜时全忘了。** 拆完立刻做一张「可借用手法清单」，写分镜时对着看。
