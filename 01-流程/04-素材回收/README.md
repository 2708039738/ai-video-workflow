# 04 · 素材回收

> 客户陆续回传，你逐条登记。**这一段决定你能不能按时开工。**

| | |
|---|---|
| **上一步给我什么** | 客户陆续回传的原片 |
| **这一步交什么** | 回收表（已交 / 待拍 / **无法拍**）+ ★ 开工包 |

---

## 做什么

**① 逐条登记，三态**

| 状态 | 含义 |
|---|---|
| 已交 | 收到且能用 |
| 待拍 | 客户答应拍，还没给 |
| **无法拍** | 客户明确说拍不了（太忙/没条件/店里没有） |

**「无法拍」必须填，不能空着。** 空着意味着你不知道缺什么，直到剪辑时才发现。

**② 三天不齐就开工**

★ 开工包到齐 → 直接排剪辑，不等其他。

**③ 缺件按话术催**

不要问「什么时候能拍」，给选择题：

> A. 这周找个下午拍一下
> B. 我用你之前发的照片顶
> C. 这场戏改掉，不拍了

客户选 B 或 C 都比拖着好。

---

## 过关

- [ ] 「无法拍」栏有内容（全齐反而可疑，说明你没问到底）
- [ ] ★ 开工包齐全，可以开工
- [ ] 每个「待拍」都有明确时间
- [ ] 已交的素材标了能用于哪几镜

---

## 需要什么能力 / 用什么

| | |
|---|---|
| 能力 | 能催、能判断素材能不能用、能当场决定「这个可以顶」 |
| 工具 | 回收表 + [催收话术](../../03-话术/催收话术.md)。**这一步不需要 AI** |

---

## 常见卡点

**等齐才开工 → 拖三天。**

素材永远收不齐。正确顺序是：★ 到了就开工，边剪边等，缺的用照片顶或改分镜。

另一个卡点：**客户发来的素材其实不能用**（横屏、带水印、糊、有竞品 logo），但你没检查就登记成「已交」。

回收时当场看一眼：画幅对不对、有没有别人的 logo、能不能用。这一眼省后面两小时。
