用途：用三组输入检查四列输出、身份约束及缺图时的推断说明，作为技能行为测试。

# 标准测试

- [ ] 在支持参考图输入并能完成四列拼版的环境中执行出图验收；能力不足时按[适配合同](../adapters/adapter-contract.md)检查对应交付，不把 `prompt_only` 计为已出图。
- [ ] 每个用例只使用本次同一人的原照片，不加入其他人物照片或私人母版。

## 用例一：最小输入

| 项目 | 内容 |
| --- | --- |
| 输入 | 只有一张正面全身照；画面中可见头发顶部、双鞋及鞋底，没有原始侧脸照片。 |
| 期望输出 | 一张横版3:2四列拼版，依次为全身照、正面、朝画面左侧特写、朝画面右侧特写；交付说明必须写“未见原始侧脸，AI 推断”，不宣称侧脸已精确还原。 |
| 失败现象 | 缺少侧脸列；右侧重复一排头像；新增第五列；把推断侧脸标为原始照片验证通过；遗漏推断说明。 |
| 这一步在测什么 | 缺少侧脸时仍能组织默认四列，并区分原照片事实与模型推断。 |

- [ ] 四个底部标签为“全身照 / 正面 / 左侧 / 右侧”。
- [ ] 核对正面身份与全身构图，并保留侧脸未核验状态；高保真用途建议补拍侧脸。

## 用例二：标准输入

| 项目 | 内容 |
| --- | --- |
| 输入 | 同一人的正面全身照、正面特写、朝画面左侧原始侧脸、朝画面右侧原始侧脸；全身照包含鞋款，各照片可辨认所需身份特征。 |
| 期望输出 | 一张横版3:2四列拼版；四列齐全，右侧只出现一组头像特写；所需视角和鞋款均有原照片证据时，无“未见原始侧脸”或“未见鞋款”缺图标注。 |
| 失败现象 | 已有左右侧脸仍标成缺少侧脸；擅自换衣、修改五官或发际线；左右朝向与标签不符；四列出现不同人物；把实际不可见的结构宣称为已核验。 |
| 这一步在测什么 | 多张原照片共同约束身份、视角和服装，母版只约束版式、颜色、标签，资料齐备时不增加无依据的缺图标注。 |

- [ ] 按[质量验收](../references/qa-checklist.md)完成七项检查。
- [ ] “无标注”只适用于所需资料确实可见的情况；如存在遮挡或模糊，仍按原文保留“模型推断 / 未核验”说明。

## 用例三：缺料输入

| 项目 | 内容 |
| --- | --- |
| 输入 | 只有一张自拍半身照，没有可见下半身、鞋款和原始侧脸。 |
| 期望输出 | 不直接交付声称精确还原的成品，先要求补充正面全身照；也可明确降级为“推断版”，说明衣裤、鞋款、身材及缺失侧脸未核验后，再尝试四列输出。 |
| 失败现象 | 未说明降级便补出下半身和鞋子；宣称身材、衣裤或鞋款来自原照片；把自拍裁切放大冒充全身照；推断版遗漏缺失资料说明。 |
| 这一步在测什么 | 缺全身照时优先补图，或明确采用推断版；不把模型补全当作原照片事实。 |

- [ ] 补图路径下先等待全身照，不交付虚构的合格最终版。
- [ ] 推断版路径下保留“未见原始侧脸，AI 推断”“未见鞋款，模型推断”，并注明不可见衣裤、身材为“模型推断 / 未核验”。
- [ ] 推断版仍检查四列数量、画面朝向、中文标签和可见身份特征，不因降级而省略验收。
