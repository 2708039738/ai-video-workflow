# 真人角色参考图 Skill — Character Reference Sheet

## 触发与范围
当用户说“调用人物参考图 Skill”“真人三视图”“全身+头像三视图”“制作数字人参考板”等时调用。每次新人物都必须重新根据当前上传照片建立身份信息，严禁继承上一位人物的五官、衣着等特征。

本 Skill 只负责**真实人物参考图**的输入分析、提示词组织、生成器选择、质量验收和交付。默认不生成Q版、动漫、表情、换装或视频。Skill 不等于人脸训练模型，不能承诺跨平台100%身份一致。

## 资料优先级
1. 用户本次上传的原始真人照片：**唯一的身份、身材、服饰事实来源**。
2. 用户指定的成品母版：**只约束版式、颜色、标签**，绝不套用母版人物的长相。
3. 本轮明确提出的改动要求；若缺失，按下列默认规则执行。
4. 不能从照片看见的侧脸、鞋子、身体结构等，标注为**模型推断 / 未核验**，不得宣称精确还原。

若可能混入不同人物的照片，应先核对而不是混合面孔生成。

## 默认输出（强制）
- 画幅：**横版3:2**，优先1536×1024或工具支持的近似高分辨率；只出**一张**四列拼版。
- 列宽：从左到右约**30% / 23.3% / 23.3% / 23.4%**，列间细分割线。
- **第1列：**正面站立完整全身照，头发顶部、双鞋鞋底完整，不裁头不裁脚；自然身材比例，不刻意把腿拉长。
- **第2列：**正面头肩特写，面向镜头，表情自然。
- **第3列：**朝**画面左侧**的近侧脸/约60–75°头像特写，尽量与用户母版一致。
- **第4列：**朝**画面右侧**的接近90°头像特写，轮廓清楚。
- 四个深灰色底部标签依次为：**全身照 / 正面 / 左侧 / 右侧**。当前命名按画面朝向；若要求严格解剖学方位，应重新定义并校正标签。
- 四列：同一真人、同一发型、眼镜、服装、肤色，**灰色摄影棚背景**；柔和均匀光照、自然肤质。可修掉强烈曝光、绿幕与镜片眩光，不擅自磨皮、美颜、瘦脸、增高、换衣服。
- **严禁右侧重复一排特写、添加第五列、贴上多张类似头像。**

更细的版式和身份规则见 [身份与版式标准](references/layout-and-identity.md)。

## 运行顺序
1. **读取照片。**标明正面全身、正面特写、朝左侧、朝右侧及其他辅助角度；检查强光、眼镜反射、遮挡、模糊与背景。
2. **建立身份特征。**提取可见的脸型、五官相对位置、发际线、发型、眼镜、耳部、肤质、体态、服装、鞋款；没有证据的结构不要编成事实。
3. **检查当前生成器能力。**根据 [适配合同](adapters/adapter-contract.md)：多参考图+编辑优先；仅单图参考则说明精度损失；只有文字生成则输出提示词；没有绘图能力只做手动交接，不能假装已生成。
4. **构建提示词。**优先使用 中文提示词（本仓库未收录），必要时使用 英文版本（本仓库未收录）。原图负责身份，母版只负责排版。
5. **生成四列图。**保持自然真实，不以审美优化牺牲辨识度；若无法生成精准中文标签，可先生成留空底栏，再在图像编辑软件中叠字。
6. **执行质检。**按 [QA清单](references/qa-checklist.md) 检查身份一致、视角方向、完整鞋子、四列数量、服装、色温、中文标签；发现失败点先局部修正，保留修订记录。
7. **交付。**默认只交付一张成品图。用户需要团队档案时另附人物ID、照片清单、后端名称、提示词版本、验收结果、未核验视角。

## 缺图/失败处理
- 缺全身照：可试做推断版，但不能声称衣裤、鞋、身材为精确还原；优先建议补全身照。
- 缺侧面：可推断，但标明“未见原始侧脸，AI推断”；高保真用途需补拍。
- 生成的人脸与原照片不一致：不得作为合格最终版交付。
- 标签乱码：优先后期叠字，而不是为了改文字重新生成全部人脸。
- 无图像生成能力：将状态写为 `prompt_only`，给出提示词与图片上传顺序。
- 公共分发：不包含当前对话中任何人物真人照片、私人母版或API密钥。

## 调用范例
“调用 `character-reference-sheet`，用我这次上传的同一人的照片，严格按默认四列母版生成，自然光照、保留真实五官，右侧不重复。缺失角度告诉我。”
