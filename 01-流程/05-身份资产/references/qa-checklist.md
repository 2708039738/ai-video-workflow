用途：按七项检查四列成品，记录不合格现象和修复动作，作为交付前的验收清单。

# 质量验收

| 怎么查 | 不合格长什么样 | 怎么修 |
| --- | --- | --- |
| ☐ 身份一致：逐列对照本次原照片，核对脸型、五官相对位置、发际线，并核对至少两项有证据的软锚点。 | ☐ 标记下颌轮廓被改写、眼距或鼻梁高度改变、唇形改变、发际线移动，或四列出现不同人物的具体位置。 | ☐ 用本次原照片重做对应列，移除母版人物特征，再按[版式与身份标准](layout-and-identity.md)复核。 |
| ☐ 视角方向：核对第2列面向镜头、第3列朝画面左侧约60–75°、第4列朝画面右侧接近90°。 | ☐ 标记左右朝向互换、两列朝同侧，或侧脸列仍面向镜头的情况。 | ☐ 修正对应列朝向，复核“左侧 / 右侧”标签；标签按画面朝向命名。 |
| ☐ 完整鞋子：查看第1列头发顶部、双鞋及鞋底，确认均未被画面边缘截断。 | ☐ 标记裁头、裁脚、缺一只鞋、鞋底被遮断，或未知鞋款未说明推断的情况。 | ☐ 调整第1列构图；缺鞋款证据时补图或注明“未见鞋款，模型推断”。 |
| ☐ 四列数量：从左到右数全身照、正面、左侧、右侧，确认只交付一张拼版且右侧只有一组特写。 | ☐ 标记少列、第五列、右侧重复一排头像，或把多张图当作一张成品交付的情况。 | ☐ 重排为一张四列拼版，补齐缺列并移除额外头像。 |
| ☐ 服装：逐列对照原照片可见的款式、领口和颜色，并核对发型、眼镜是否跨列保持一致。 | ☐ 标记领口变化、服装换色、擅自换衣、眼镜消失或发型跨列变化的情况。 | ☐ 按本次原照片修正对应列；不可见部分注明推断，不套用母版人物的衣着。 |
| ☐ 色温：并排比较四列肤色、服装颜色与灰色摄影棚背景，检查曝光、色温及镜片反射。 | ☐ 标记单列偏绿或偏黄、肤色跨列变化、曝光遮住五官，或镜片眩光遮住眼睛的情况。 | ☐ 局部修正曝光、色温、绿幕残留和眩光，复核五官与肤色，保留肤质。 |
| ☐ 中文标签：逐字核对四个深灰色底部标签依次为“全身照 / 正面 / 左侧 / 右侧”。 | ☐ 标记乱码、缺字、错字、顺序互换、标签重复或底栏缺失的情况。 | ☐ 在图像编辑软件中叠字并校正标签，不为改文字重新生成全部人脸。 |

- [ ] 总判定：身份一致、四列数量为阻断项，任一项未通过即不能作为合格最终版交付；其余五项为返修项，未通过时先局部修正并复查，全部通过后再交付。
- [ ] 对缺失原始视角或鞋款保留推断说明，不把“未核验”记成“已精确还原”。
- [ ] 记录失败位置、修正动作和复查结果，保留修订记录。
