用途：细化四列母版的像素取整、身份判定和缺失资料标注，供生成与返修时核对。

# 版式与身份标准

## 四列比例、取整与容差

| 列 | 内容与底部标签 | 目标比例 | 1536×1024 导出时的列尺寸 |
| --- | --- | --- | --- |
| 第1列 | 正面站立完整全身照；全身照 | 约30% | 461×1024像素 |
| 第2列 | 正面头肩特写；正面 | 约23.3% | 358×1024像素 |
| 第3列 | 朝画面左侧、约60–75°头像特写；左侧 | 约23.3% | 358×1024像素 |
| 第4列 | 朝画面右侧、接近90°头像特写；右侧 | 约23.4% | 359×1024像素 |

- [ ] 母版保持横版3:2；1536×1024是优先导出尺寸，不代表平台分辨率上限。
- [ ] 在其他导出宽度下，先将总宽度分别乘以前三列比例并取整，再把剩余像素分给第4列；四列宽度之和等于总宽度。
- [ ] 将“接近即可”理解为每列相对目标宽度上下约1个百分点的排版容差；1536像素宽时约为上下15像素，不按比例的小数位逐项卡死。
- [ ] 取整和容差均不增加画布宽度；列间细分割线计入列宽，不额外形成第五列。
- [ ] 左侧保留一列全身照，右侧只保留一组正面、左侧、右侧特写，不重复一排头像。

## 身份锚点清单

| 分组 | 锚点 | 核对内容 |
| --- | --- | --- |
| 硬锚点：变一项就不是同一人 | 脸型 | 对照原照片核对额头、颧部、下颌和下巴轮廓，区分视角造成的变化与轮廓被改写。 |
| 硬锚点：变一项就不是同一人 | 五官相对位置 | 对照相应角度核对眼距、鼻梁高度、唇形，不以美颜后的五官替代原照片。 |
| 硬锚点：变一项就不是同一人 | 发际线 | 核对额角、前额边界及可见转折，不用发型遮挡掩盖发际线变化。 |
| 软锚点：变化不单独否定身份 | 发型细节 | 核对分缝、刘海和可见发束；少量发丝变化不单独判为换人。 |
| 软锚点：变化不单独否定身份 | 肤色深浅 | 区分曝光、色温变化与肤色被改写；不把光照差异单独判为换人。 |
| 软锚点：变化不单独否定身份 | 体型胖瘦 | 核对可见体态；不把透视差异单独判为换人，也不擅自瘦身、增高。 |
| 软锚点：变化不单独否定身份 | 服装 | 核对原照片可见的领口、款式和颜色；换衣不单独否定身份，但违反默认服装要求。 |
| 软锚点：变化不单独否定身份 | 鞋款 | 核对可见鞋型、鞋底和颜色；没有鞋款证据时标注推断。 |

- [ ] “同一人”判定：三项硬锚点全部通过，并且至少两项有原照片证据的软锚点一致。
- [ ] 某项硬锚点因遮挡或缺图无法核对时，记为未核验，不把推断计作通过；先补图或说明推断范围。
- [ ] 软锚点允许变化仅用于身份判定；默认成品仍保持同一发型、眼镜、服装、肤色，不据此擅自换衣或美颜。
- [ ] 身份只以本次原始真人照片为准；母版只约束版式、颜色、标签。

## 必须重做的四种情况

- [ ] 脸型、五官相对位置或发际线有一项被改写，或四列出现不同人物：重做对应列，重新核对身份。
- [ ] 出现第五列、右侧重复一排特写，或少于四列：重排四列，移除重复内容或补齐缺列。
- [ ] 第3列朝画面右侧、第4列朝画面左侧，或两列都画成同一朝向：重做对应视角，按画面朝向校正标签。
- [ ] 第1列头发顶部、任一鞋子或鞋底被画面边缘截断：重做对应列的构图，保留完整全身。

## 缺失资料的标注格式

| 缺失内容 | 标注文字 |
| --- | --- |
| 没有原始侧脸照片 | 未见原始侧脸，AI 推断 |
| 没有可见鞋款 | 未见鞋款，模型推断 |
| 其他不可见身体结构 | 模型推断 / 未核验，并注明具体部位。 |

- [ ] 将推断说明写入交付说明；四个底部标签仍为“全身照 / 正面 / 左侧 / 右侧”。
- [ ] 缺侧脸且用于高保真用途时建议补拍，不把生成的角度宣称为精确还原。
