# 素材可用性判定手册

> **用法：** 客户素材到手，**先判定，再谈需求和报价**。顺序反了就会承诺做不了的东西（`实例`：某驾校素材清单改 4 版，根因就是先定了方案后看素材）。
> **前提：素材通常补不了。** 所以本手册的重点不是"让客户重拍"，是"这份素材能做成什么"。
> 标记：`实例` = 真实踩过的坑；`推演` = 按原理推的。

---

## 一、三档判定

拿到每份素材，先归入一档：

| 档 | 含义 | 处理 |
|---|---|---|
| **A 直接用** | 清晰、合规、构图够用 | 进素材库，标编号 |
| **B 能救** | 有缺陷，但有替代做法 | 写明怎么救，成本多高 |
| **C 不能救** | 救的成本高于重做方案 | 换方案，或明确告诉客户这段做不了 |

**C 档不代表项目做不了，代表"这段素材没有用武之地"。** 一场片子里 3–5 个镜头不需要实拍素材，可以纯生成或纯后期。

---

## 二、照片类

**1. 模糊 / 对不上焦**

| | |
|---|---|
| 判定 | 放大到 100%，主体边缘有没有清晰轮廓 |
| 能做 | 只做背景/氛围参考，不做主体 |
| 不能做 | 做人物参考图（生成出来也会糊） |
| 替代 | 用同场景另一张清晰图 + 生成补主体 |

**2. 太暗 / 过曝**

| | |
|---|---|
| 判定 | 主体细节还能不能看出来 |
| 能做 | 暗图可以往"氛围感"方向做；过曝基本没救 |
| 不能做 | 需要展示产品细节的镜头 |
| 替代 | 产品改用户提供的官方图/渲染图 |

**3. 逆光**

| | |
|---|---|
| 判定 | 人脸是不是一团黑 |
| 能做 | 剪影、氛围镜 |
| 不能做 | 需要看清表情的镜头 |
| 替代 | 换一张顺光的，或改成分镜里的背影/侧影 |

**4. 画面里有其他人（路人、顾客、同行）**

| | |
|---|---|
| 判定 | 这些人是否可识别（正脸、清晰）、是否穿别家制服 |
| 能做 | 虚化/裁切后使用 |
| 不能做 | 出现别家 logo、制服（合规红线） |
| 替代 | 裁切、局部替换、或改成纯生成场景 |
| 实例 | 素材带竞品 logo 是曾经踩过的交付风险 |

**5. 没有全身照**

| | |
|---|---|
| 判定 | 人物参考图是否够用 |
| 能做 | 半身/特写镜头 |
| 不能做 | 全身镜头、走位镜头 |
| 替代 | 按 `05-身份资产` 的做法：标"模型推断"，不声称精确还原 |

**6. 有美颜 / 滤镜**

| | |
|---|---|
| 判定 | 皮肤有没有磨平、五官有没有变形 |
| 能做 | 氛围镜 |
| 不能做 | 做人物身份参考（生成会继承变形） |
| 替代 | 找一张原图（往往是客户自己手机里没发朋友圈的那张） |
| 备注 | 客户发来的图经常是"发过的"，已经被压过一遍 |

**7. 截图（带手机 UI、带聊天框）**

| | |
|---|---|
| 判定 | 主体在截图里占多大 |
| 能做 | 只做参考，不做素材 |
| 不能做 | 直接入片（分辨率不够，且带 UI） |
| 替代 | 让客户发原图；或按截图重拍一张 |

**8. 带水印 / 别家 logo**

| | |
|---|---|
| 判定 | 能不能裁掉 |
| 能做 | 裁切后使用 |
| 不能做 | **任何情况下带别家 logo 入片** |
| 替代 | 裁切、局部替换、或不用这段 |

**9. 横竖构图不对**

| | |
|---|---|
| 判定 | 竖屏素材要做横版，反之 |
| 能做 | 竖转横：主体居中可裁；横转竖：主体偏一侧可裁 |
| 不能做 | 主体横跨整个画面时硬裁（会切掉关键信息） |
| 替代 | 用生成补画幅，或改成分屏/画中画 |

**10. 眼镜反光**

| | |
|---|---|
| 判定 | 反光是否遮住眼睛 |
| 能做 | 侧面、低头角度 |
| 不能做 | 正面特写 |
| 替代 | 换角度，或后期修 |

## 三、视频类

**11. 手持抖**

| | |
|---|---|
| 判定 | 抖到什么程度——是"真实感"还是"看不清" |
| 能做 | 轻微抖反而有真实感，可直接用 |
| 不能做 | 抖到主体模糊 |
| 替代 | 抽一帧做首帧，用生成补 |

**12. 声音噪 / 听不清**

| | |
|---|---|
| 判定 | 有没有可用的人声段 |
| 能做 | 环境音、氛围音 |
| 不能做 | 做口播/对白 |
| 替代 | 后期配音；或整段静音 + 配乐 |

**13. 背景乱**

| | |
|---|---|
| 判定 | 主体能不能被裁出来 |
| 能做 | 裁切、虚化 |
| 不能做 | 需要干净背景的产品展示 |
| 替代 | 生成补背景，或用抠像 |

**14. 时长太短（低于 4 秒）**

| | |
|---|---|
| 判定 | 实际可用秒数（去掉头尾抖动） |
| 能做 | 4 秒以上：直接剪 |
| 不能做 | 2 秒以内：凑不出一个镜头 |
| 替代 | **补长优先冻帧，不要慢放、不要循环**（`实例`：火锅项目 4.168s / 4.512s 两条短素材，冻帧补到可用长度） |
| 补充 | 冻帧 ＞ 慢放 ＞ 循环。慢放会改变动作节奏，循环会看出接缝 |

**15. 分辨率低**

| | |
|---|---|
| 判定 | 素材像素 vs 成片像素（竖屏 1080×1920） |
| 能做 | 小尺寸展示位、画中画、背景 |
| 不能做 | 全屏主画面 |
| 替代 | 降级使用，或用生成重做 |

**16. 有路人穿过画面**

| | |
|---|---|
| 判定 | 穿过后主体还在不在 |
| 能做 | **反而是加分项**——遮挡再露出是去 AI 感的常用手法 |
| 不能做 | 路人挡住主体的关键动作 |
| 替代 | 剪掉遮挡段，或用这一帧做遮挡转场 |

## 四、不能救的时候怎么办（不重拍）

**核心思路：改方案，不改素材。**

| 情况 | 替代方案 |
|---|---|
| 没有实拍素材 | 纯生成（含产品图/渲染图做底） |
| 人物素材不合格 | 数字人 / 只用背影侧影 / 出镜改成画外音 |
| 场景素材不行 | 生成场景 + 合成人物 |
| 产品细节不清 | 用官方图/渲染图做底，环境另做 |
| 缺关键角度 | 标"模型推断"，不声称还原 |
| 整体素材不足 | **缩片长**：15 秒做不了就做 8 秒，比堆素材强 |

**最后一条最重要。** 素材撑不起 30 秒，做 15 秒的完整片子，比做 30 秒的拼凑片子值钱。

## 五、判定记录表（发给客户前先填）

| 素材编号 | 内容 | 档 | 能做 | 不能做 | 救法 |
|---|---|---|---|---|---|
| M01 | 门店全景 | A | 开场、环境交代 | — | — |
| M02 | 老板半身 | B | 口播特写 | 全身走位 | 缺全身，标推断 |
| M03 | 菜品 | A | 产品特写 | — | — |
| M04 | 顾客反应 | C | — | — | 路人不可识别，改用生成 |

**这张表填完，再谈报价。** 填不出来的项目，就是做不了的项目。

---

## 六、一句话

**素材决定片子能做成什么，不是需求决定。**

客户说"我要 30 秒大片"，先看素材够不够 30 秒。不够就当场说，别等做完再说。
