# 生成翻车诊断手册

> **用法：** 生成出来不对，先在第二节找症状，按"30 秒判定"确定原因，再决定改不改。
> **不要凭感觉重抽。** 每次重抽都要能说出"我改了哪一项"。
> 标记：`实例` = 本项目真实踩过的坑；`推演` = 按原理推的，未实测。

---

## 一、先分清是哪一类问题

翻车只有三种原因。**分不清就重抽，是最大的浪费。**

| 类型 | 特征 | 怎么验证 |
|---|---|---|
| **A 提示词问题** | 描述模糊、有歧义、缺关键约束 | 换一句更具体的描述，其他不动 |
| **B 模型能力边界** | 再怎么写也做不到 | 换最简单的描述试，仍然不行 |
| **C 素材问题** | 参考图本身有缺陷 | 看首帧图，图里就没有/就错 |

**判定方法：单变量法**

只改一个地方，其他全部不动，再跑一次：

- 改了就对了 → A 提示词问题
- 改了还是错 → B 模型边界
- 改之前先看图，图上就错 → C 素材问题

**C 类最容易被误判成 A。** 首帧图上人物就没有内搭，你再怎么写提示词也长不出来（`实例`：稣文 V02 模特内搭消失，生出来才发现）。

## 二、症状对照表

### 人物类

**1. 脸不像同一个人（跨镜）**

| | |
|---|---|
| 最可能原因 | 每镜独立生成，没有共享参考 |
| 30 秒判定 | 两镜的人脸放一起看，是同一张脸吗 |
| 改法 | 同一人物的镜头归一组 `same_take_group`，同一条生成后剪；或每镜都带同一张正面参考图 |
| 放弃条件 | 试过 2 次仍不像 → 改用局部替换或后期遮脸 |

**2. 手指变形、多指**

| | |
|---|---|
| 最可能原因 | 手部细节是模型公认弱项（`推演`+行业普遍现象） |
| 30 秒判定 | 手在画面里占多大？小于 1/10 画面就别纠结 |
| 改法 | ①手不接触物体 ②减少手部入画 ③改成实拍 |
| 放弃条件 | 手是主角（做菜、递东西）→ **直接实拍**，不要抽 |

**3. 服装/配饰变了**

| | |
|---|---|
| 最可能原因 | 参考图里这件东西不清楚，或提示词没锁 |
| 30 秒判定 | 看首帧图，衣服对不对 |
| 改法 | 首帧图上就错 → 回去改图；首帧对但生成后变 → 提示词加"服装不得改变" |
| 实例 | 稣文 V11 蛇形耳环"焊进脸部里"——配饰越精细越容易崩 |

**4. 内搭/细节消失**

| | |
|---|---|
| 最可能原因 | 生图阶段就丢了，不是生视频丢的 |
| 30 秒判定 | 放大首帧图看该位置 |
| 改法 | **回到图片阶段补**，不要在视频阶段改提示词 |
| 实例 | 稣文 V02，抬头后内搭不见了 |

### 动作类

**5. 动作没发生**

| | |
|---|---|
| 最可能原因 | 提示词里没有一个明确的主动作，或动作被拆成多个 |
| 30 秒判定 | 提示词里有几个动词？超过 2 个就是问题 |
| 改法 | 只保留一个主动作，写成"起→中→终"三段 |
| 放弃条件 | 一镜里必须有两个以上动作 → 拆镜 |

**6. 动作幅度过大、画面糊**

| | |
|---|---|
| 最可能原因 | 动作描述没有幅度约束 |
| 改法 | 加"幅度极小""只有发丝和衣角轻微摆动"这类约束 |
| 实例 | 稣文 V02：靠微动态给呼吸感，别让 AI 大动 |

**7. 人物没按预期方向走/转身**

| | |
|---|---|
| 最可能原因 | 方向描述用了相对词（"向左""转身"） |
| 改法 | 用画面方位，不用人物视角："向画面左侧移动" |
| 备注 | 这是"左"的歧义高发区，和参考图标签同一个问题 |

### 镜头类

**8. 镜头没动**

| | |
|---|---|
| 最可能原因 | 提示词写了两个以上运动，模型选了一个或不选 |
| 改法 | **一条提示词只写一种镜头运动** |
| 备注 | `09-提示词编译/SKILL.md` 的必填字段已经写死这条 |

**9. 镜头乱动、漂移**

| | |
|---|---|
| 最可能原因 | 没有指定机位固定，或参考视频本身在动 |
| 改法 | 加"固定机位"，或明确"仅轻微推进" |

**10. 运镜方向反了**

| | |
|---|---|
| 最可能原因 | 相对方位描述 |
| 改法 | 换成"画面从左向右横移" |

### 光线与色彩类

**11. 光源方向跳了（相邻镜头）**

| | |
|---|---|
| 最可能原因 | 每镜独立生成，没有共享光位描述 |
| 30 秒判定 | 两镜并排看，影子朝哪边 |
| 改法 | 每镜都写同一句光源："主光来自画面左上方窗户" |
| 为什么是硬性 | 观众说不清哪假，但立刻觉得"这是拼的"（`实例`：稣文 V14 原话） |

**12. 色温突变（一镜暖一镜冷）**

| | |
|---|---|
| 最可能原因 | 没写色温 |
| 改法 | 每镜写"色温偏暖/偏冷"，同一空间统一 |

**13. 画面发灰、没有层次**

| | |
|---|---|
| 最可能原因 | 缺少前景/背景关系描述 |
| 改法 | 补"前景有××，中景是主体，背景虚化" |
| 备注 | 这条常和"没有真实感"是同一个问题 |

### 文字类

**14. 画面里出现乱码中文**

| | |
|---|---|
| 最可能原因 | 让模型自己写字了 |
| 30 秒判定 | 提示词里有没有提"屏幕/招牌/字幕/文字" |
| 改法 | 三选一：绕开（只送无文字片段）/ 代码合成 / 正面复刻（给坐标字号色值） |
| 实例 | 某甜品店 F09 手机屏，出来"滴原自口果汤米" |

**15. 出现了不该有的文字/水印**

| | |
|---|---|
| 最可能原因 | 参考图自带 |
| 改法 | 换参考图，或在负面约束里写明 |
| 备注 | 别家 logo 一律算不合格（单镜验收单第 9 项） |

### 画面内容类

**16. 多出物体/少了物体**

| | |
|---|---|
| 最可能原因 | 提示词没锁"不能变的东西" |
| 改法 | 稣文 V18 的做法：只锁定三件事——**人物怎么动、镜头怎么动、哪些东西不能变** |
| 备注 | 不要试图描述所有细节，只锁关键的三条 |

**17. 产品结构和实物不一致**

| | |
|---|---|
| 最可能原因 | 模型按"常见样子"补全 |
| 改法 | 生成前过一遍结构清单（单杆/多杆、轮纹、扣具、管材圆扁、印花方向、折叠厚度） |
| 实例 | 稣文 V20：单杆婴儿车被 AI 多加一根杆，普通观众看不出，甲方一帧一帧对比就看出来了 |

**18. 背景变成了另一个地方**

| | |
|---|---|
| 最可能原因 | 背景描述太泛（"街道""室内"） |
| 改法 | 给具体特征："胡桃木色墙面、左侧有窗、地面是深灰地砖" |

### 综合类

**19. 一切都对，但"就是假"**

这是最难的一类，按顺序查四件事：

1. **光**：光源方向一致吗？色温统一吗？
2. **动**：摄影机为什么动？人物为什么动？有没有理由？
3. **细节**：前景有没有东西？画面是不是太干净？
4. **帧率**：动态镜头是 24 帧吗？

稣文原话：「没有 AI 感不等于画面清晰度越高越好，而是摄像机为什么动、人物为什么动、环境为什么动，都要有理由。」

**20. 抽了 10 次还是不行**

不是提示词问题，是**这个镜头不该用 AI 做**。

| 情况 | 结论 |
|---|---|
| 手与道具精细交互 | 实拍 |
| 精确文字（招牌、价签、地址） | 后期层 |
| 多人同框对视/对话 | 实拍，或拆正反打 |
| 产品结构必须精确 | 用渲染图做底，别生成 |

答案在 `09-提示词编译/SKILL.md` 的路线分档表里，翻回去看。

## 三、什么时候必须放弃生成

**抽卡成本超过实拍成本时，就该停。**

粗略换算：

```
一次生成 ≈ 3–10 分钟 + 积分
一镜抽 5 次 ≈ 半小时
实拍一个简单镜头 ≈ 20 分钟（有素材的情况下）
```

**如果同一镜已经抽了 5 次还没过，停下来问：这个镜头实拍要多久？**

稣文的做法值得学：品牌印花 AI 做不一致，他「放弃完全通过 AI 制作这个图片」→ **先 PS 修图定死细节，再生视频**（V03）。

**AI 不擅长的地方退回传统管线，而不是无限抽卡。**

## 四、每次翻车记一行

```
S03 v02 ｜ 症状：动作没发生 ｜ 判定：提示词里有 3 个动词 ｜ 改法：只留"停止并悬停" ｜ 结果：过了
S07 v01 ｜ 症状：手指变形 ｜ 判定：手占画面 1/3，是主角 ｜ 结论：改实拍
```

记满 20 行，你就有了自己的症状库——比这份手册准。
